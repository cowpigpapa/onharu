# 온하루 · ONHARU 사용자 설명서

## 다운로드

- [ONHARU 2.2.4 설치 프로그램과 ZIP 다운로드](https://github.com/cowpigpapa/onharu/releases/tag/v2.2.4)
- 지원 환경: Windows 10/11 x64
- 이번 개인 프리웨어 배포판은 코드 서명되지 않아 Windows SmartScreen에서 `알 수 없는 게시자` 경고가 나타날 수 있습니다. 공식 릴리스의 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.

2.2 화면 하단은 `MADE BY JUAN.HJLEE · ONHARU (ver. 2.2.4)`로 표시합니다.

## 2.2 디자인 스킨

2.2는 2.1의 기능과 Explorer 레이어를 유지하면서 `파스텔`, `블랙` 두 가지 외형을 선택할 수 있게 합니다. 스킨은 화면 코드를 복제하지 않고 공통 의미 팔레트를 교체하므로 기능 수정은 두 스킨에 동일하게 반영됩니다.

Google Calendar 연결은 Desktop OAuth와 PKCE를 사용합니다. OAuth 자격 증명은 공개 저장소에 올리지 않고 로컬 빌드 전용 파일에서 주입합니다.

온하루는 Windows 바탕화면에 계속 보이는 월간 달력입니다. 하루 종일 일정, 시간별 Todo, 업무/개인 일정과 Google Calendar를 한 화면에서 관리할 수 있습니다.

## 2.1에서 추가된 기능

- 설정에서 일기장을 켜면 날짜 숫자를 더블클릭해 일기를 쓰고, 상단 일기장 아이콘에서 날짜·제목 검색과 최신순/오래된순 읽기를 사용할 수 있습니다.
- Google Tasks는 명시적으로 기능을 켠 경우에만 별도 목록과 완료 상태를 동기화합니다. Google Calendar 일정과 Google Task는 서로 다른 데이터입니다.
- 일정 관리는 ONHARU JSON 백업·복원, 표준 ICS 가져오기·내보내기, Google 포함 전체 일정 Excel CSV 내보내기를 구분합니다.
- 프로야구 일정은 사용자가 발급받은 Parse.bot API 키를 Windows 계정에 암호화해 저장합니다. 4주/월간 보기, 응원팀 최대 2개, 경기 선택 후 `야구` 로컬 일정 등록을 지원합니다.

- 일반 D-Day 일정과 생일·결혼기념일 같은 기념일을 분리해 오른쪽의 독립된 D-Day/기념일 카드에서 확인할 수 있습니다.
- 일정 등록·수정창의 `기념일로 등록`으로 로컬 기념일을 만들 수 있으며, 이후에는 전용 기념일 창에서 날짜·종류·D-Day 표시를 관리합니다.
- 기념일은 최대 10개까지 등록하고 기본 5개를 표시합니다. 일반 D-Day와 기념일 영역은 각각 접기·펼치기와 더보기를 지원합니다.
- 기념일 수정창의 `일정으로 변경`으로 일반 로컬 일정 또는 D-Day 일정으로 되돌릴 수 있습니다.

- 새 일정의 기본 캘린더·종일 여부·시작 시간·소요 시간·알림을 설정할 수 있습니다.
- 알림을 분·시간·일 단위로 직접 지정하고, 소리와 조용한 시간을 선택할 수 있습니다.
- 달력 제목을 눌러 연도와 월로 바로 이동합니다.
- 완료 일정은 그대로 표시하거나 흐리게 또는 숨길 수 있습니다.
- 검색 범위를 과거·미래·전체 또는 사용자 지정 시작일·종료일로 고릅니다.
- 반복 일정은 종료일뿐 아니라 N회 후 종료할 수 있습니다.
- 일반 일정에는 D-Day/D-n/D+n을 표시하고, 기념일에는 최초 기준일부터의 누적 일수와 다음 기념일까지 남은 날짜를 표시할 수 있습니다.
- 시작 날짜와 위치 고정 상태를 사용자가 선택할 수 있습니다.
- 선택형 시간표 기능을 켜면 월~일 표시 요일, 1~12교시, 시작 시각, 수업·쉬는 시간을 설정하고 과목·장소를 별도 팝업에서 관리할 수 있습니다.

## 1. 실행하기

1. `ONHARU-2.2.3-Setup.exe`를 실행해 설치합니다.
2. 온하루는 작업표시줄의 일반 창이 아니라 바탕화면 레이어에 표시됩니다.
3. 화면 오른쪽 아래 알림 영역에도 온하루 아이콘이 생깁니다.
4. 오른쪽 위 `×`의 기본 동작은 트레이 최소화입니다. 완전히 종료하려면 트레이 메뉴의 `종료`를 사용합니다.

설치 프로그램은 시작 메뉴와 제거 프로그램을 만들며, 설치 중 바탕화면 바로가기와 Windows 자동 실행을 선택할 수 있습니다. 기존 ONHARU 설치판이 있으면 같은 AppId를 사용해 제거 없이 2.2.3으로 업그레이드하고 일정·설정·Google 연결 데이터는 보존합니다. 사용자 승인형 자동 업데이트는 포함되며 Windows 코드 서명은 아직 적용하지 않았습니다.

파일명이 다른 이전/새 버전 EXE를 함께 실행할 수 없습니다. 온하루는 계정·설정·Google 토큰을 안전하게 관리하기 위해 Windows 사용자당 한 창만 실행됩니다.

## 2. 화면 구성

### 상단

- `온하루 · ONHARU`: 앱 이름과 현재 연월
- 이전/다음 화살표: 월 이동
- 시간표 아이콘: 설정에서 시간표 기능을 켠 경우 시간표 보기·편집
- 오늘: 이번 달과 오늘 날짜로 복귀
- 위치 버튼: 위치·크기 조정/현재 위치로 고정 전환
- `G 연결` 또는 `G 동기화`: Google 로그인과 수동 동기화
- 검색 아이콘: 일정 검색
- 톱니바퀴: 설정
- `×`: 설정한 기본 동작 실행. 오른쪽 클릭하면 취소·최소화·종료 메뉴 표시

### 월간 달력

- 토요일 날짜: 파란색
- 일요일 및 국경일 날짜: 빨간색
- 오늘: 옅은 핑크 배경과 `오늘` 문구
- 중요 일정: `★`와 핫핑크 굵은 글씨
- 달력에 표시하는 주 수와 셀 높이에 따라 일정 표시 개수가 자동 조정되며, 넘치는 일정은 셀 아래의 더보기 표시로 확인

### 오른쪽 일정 패널

- 선택한 날짜의 일정을 캘린더/카테고리별 파스텔 카드로 표시합니다.
- 시간 Todo와 로컬 업무/개인 하루 종일 일정에는 완료 체크박스가 있습니다.
- `선택일 / 이번 주 / 다음 주`를 전환해 하루 또는 2주 범위의 일정을 빠르게 확인할 수 있습니다.
- 날짜 제목 옆 색상 버튼에서 선택 날짜 전체의 옅은 배경색을 지정하거나 지울 수 있습니다.
- 패널 왼쪽의 화살표로 접을 수 있으며, 접으면 달력이 넓어집니다.
- 위쪽 Google 계정 표시를 누르면 동기화 대기 일정 목록을 확인할 수 있습니다.

## 3. 창 이동, 크기와 클릭

### 위치 이동

1. 압정 버튼을 눌러 `이동 가능`으로 바꿉니다.
2. 상단의 버튼이 없는 빈 공간을 잡고 이동합니다.
3. 원하는 위치에서 다시 눌러 `고정됨`으로 바꿉니다.

위치, 크기, 고정 상태는 종료 시 저장되어 다음 실행에 복원됩니다.

저장된 위치의 모니터가 연결되지 않은 상태로 실행하면 온하루가 현재 주 모니터 중앙으로 자동 이동합니다. 실행 중 모니터를 분리했는데 보이지 않는 경우에는 알림 영역의 온하루 아이콘을 오른쪽 클릭하고 `현재 화면으로 가져오기`를 선택합니다.

### 크기 변경

- 위치·크기 조정 상태에서 네 모서리 또는 상·하·좌·우 가장자리를 드래그합니다.
- ONHARU 전용 크기 조절 커서가 방향에 맞게 표시됩니다.

### 고정 상태와 바탕화면 아이콘

- 고정하면 ONHARU가 `배경화면 < 달력 < 바탕화면 아이콘 < 일반 창` 순서로 Explorer에 합성됩니다.
- 달력 위에 놓인 바탕화면 아이콘도 선택·드래그·실행할 수 있습니다.
- 고정 상태에서도 날짜 선택, 일정 체크, 스크롤, 새 일정 등록과 일정 수정이 가능합니다.
- 달력의 일정 막대를 한 번 클릭하면 해당 칸의 날짜가 선택되고, 두 번 클릭하면 기존처럼 일정 수정창이 열립니다.

## 4. 일정 등록

날짜의 빈 공간을 더블클릭하거나 오른쪽 패널 아래의 일정 추가 버튼을 누릅니다.

1. 날짜를 확인합니다. 신규 일정은 더블클릭한 날짜로 고정됩니다.
2. 제목을 입력합니다. 제목은 필수입니다.
3. 시간 옵션을 선택합니다.
   - 하루 종일: 로컬 업무/개인 일정은 자동으로 완료 체크 가능
   - 오전/오후 + 1~12시 + 0/15/30/45분: 완료 가능한 Todo
   - 하루 종일에서 `여러 날 일정`을 선택하면 종료 날짜까지 이어지는 막대 일정
   - 여러 날 일정은 `없음` 또는 `매주`만 선택 가능하며, 매주는 시작 요일부터 같은 기간으로 반복
4. 자동 이월을 선택합니다. 기본은 `이월 안 함`입니다.
5. 저장 위치를 선택합니다.
   - 온하루 업무일정/개인일정: 이 PC의 현재 계정 파일에만 저장
   - Google 캘린더 이름: 선택한 Google 캘린더에 동기화
6. 알림, 중요 일정, 반복, 메모를 설정합니다.
7. `일정 저장`을 누르거나 메모 입력 중이 아닐 때 Enter를 누릅니다.

제목이 없으면 별도 경고창 대신 입력창 안에 빨간 안내가 잠시 표시됩니다.

## 5. 일정 수정과 삭제

### 수정

- 달력 칩 또는 오른쪽 패널의 일정을 더블클릭합니다.
- `날짜 변경`을 누르면 팝업 달력이 열립니다.
- 날짜를 선택하고 바깥을 클릭하거나 날짜를 더블클릭하면 적용됩니다.
- 수정창 제목 옆의 배지에서 `온하루 등록`인지 `Google Calendar`인지 확인할 수 있습니다.

Google 휴일 또는 설정에서 수정 불가로 지정한 캘린더는 수정할 수 없습니다. 안내는 클릭한 일정 가까이에 잠시 표시됩니다.

### 반복 일정 수정

반복 종류에 따라 다음 세부 옵션을 선택할 수 있습니다.

- 매일: 매일 또는 평일만
- 매주: 월·화·수·목·금·토·일 복수 선택
- 매월: 같은 날짜, n번째 같은 요일, 마지막 날
- 매년: 같은 월·일
- 모든 반복: 종료일 또는 N회 후 종료

- 기본: 해당 반복 일정 전체를 수정합니다.
- `이번 일정만 변경` 체크: 선택한 날짜의 일정만 별도로 수정합니다.

### 반복 일정 삭제

삭제 버튼을 누르면 다음 중 하나를 고릅니다.

- 이번 일정만: 선택한 한 번만 삭제
- 이번 일정부터 미래: 이전 기록을 남기고 선택한 날짜부터 제거
- 과거 포함 전체: 과거와 미래를 포함한 반복 전체 삭제

반복이 아닌 일정은 즉시 해당 일정만 삭제합니다.

## 6. Todo 완료와 자동 이월

- 시간이 있는 일정과 로컬 업무/개인 하루 종일 일정의 체크박스를 누르면 완료됩니다.
- 완료된 일정은 취소선으로 표시됩니다.
- 설정의 `완료 Todo는 아래로 이동`을 켜면 완료 즉시 해당 날짜 일정의 아래쪽으로 정렬됩니다.
- 자동 이월 옵션:
  - 이월 안 함
  - 다음 날
  - 다음 주 같은 요일
  - 다음 평일
- 미완료이며 날짜가 지난 Todo만 이동합니다.

### Google Tasks 연동 범위

- Google Tasks는 기본적으로 꺼져 있습니다. 설정의 `Google Tasks 표시·동기화`를 켜고 제한 사항 안내에 동의한 경우에만 동기화되고 오른쪽 Google 목록에 표시됩니다.
- 기능을 켜면 설정의 `Google 일정 수정 권한`에도 Task 목록이 나타납니다. 해당 목록의 `ONHARU 등록 Task`를 체크하면 새 일정 화면에서 Google Task를 저장 대상으로 선택할 수 있습니다.
- Google Tasks에서 API로 제공되는 할 일은 ONHARU에 하루 종일 Todo로 표시됩니다.
- 완료·미완료 상태는 ONHARU와 Google Tasks 사이에 양방향으로 동기화됩니다.
- ONHARU에서 만든 Google Task는 제목·날짜·메모·완료 상태를 수정하고 삭제할 수 있지만 반복·시간·알림·여러 날 일정은 지원하지 않습니다.
- Google에서 만든 Task는 반복 여부를 API로 판별할 수 없어 ONHARU에서는 완료 상태만 변경할 수 있습니다.
- Google Tasks 공개 API는 반복 규칙과 미래 반복 회차를 제공하지 않습니다. 따라서 ONHARU는 Google이 공개한 현재 회차만 표시하며 반복 일정을 임의로 생성하지 않습니다.
- Google Tasks 공개 API의 마감일은 날짜만 제공하고 설정된 시각은 제공하지 않습니다. Google Tasks에서 `09:00`처럼 시간을 지정했더라도 ONHARU에서는 하루 종일 할 일로 표시됩니다.
- 미래 반복 회차와 정확한 시간이 모두 필요한 일정은 Google Task 대신 Google Calendar 반복 일정 또는 ONHARU 반복 일정으로 등록하세요.

이 제한은 ONHARU의 날짜 조회 범위가 아니라 Google Tasks 공개 API의 데이터 구조 때문입니다. 자세한 내용은 [Google Tasks API의 Task 리소스 설명](https://developers.google.com/workspace/tasks/reference/rest/v1/tasks)을 참고하세요.

## 7. 알림

등록/수정창에서 다음 중 선택합니다.

- 없음
- 정시
- 10분 전
- 30분 전
- 하루 전
- 직접 지정: 1~999 분/시간/일 전

알림 시각이 되면 모니터 중앙에 온하루 알림이 표시됩니다. 확인하거나 다시 알림을 선택할 수 있습니다. 설정에서 알림 소리를 끄거나 조용한 시간을 지정할 수 있으며, 조용한 시간에도 팝업은 표시됩니다. 온하루가 완전히 종료된 동안에는 자체 알림이 표시되지 않습니다. Google 일정의 Google 측 모바일/이메일 알림은 Google Calendar 설정에 따릅니다.

## 8. Google Calendar 연결

### 최초 연결

1. 상단 `G 연결`을 누릅니다.
2. 브라우저에서 Google 계정을 선택하고 권한을 승인합니다.
3. `온하루 연결이 완료되었습니다` 페이지가 보이면 브라우저 창을 닫습니다.
4. 온하루가 내 캘린더, 팀, 가족, 생일, 휴일 등 해당 계정의 목록을 읽습니다.

로그인 브라우저를 닫거나 응답하지 않으면 최대 5분 후 취소 처리됩니다. 기다리는 동안 온하루의 `로그인 취소` 버튼으로 즉시 중단할 수도 있습니다. 권한 확인이 길어져도 로컬 콜백 수신기를 먼저 닫지 않아 `127.0.0.1 연결 거부`를 예방합니다.

### 동기화

- `G 동기화`: 즉시 양방향 동기화
- 성공: `동기화가 완료되었습니다`가 1초 표시
- 실패: 로컬 변경을 보존하고 자동 재시도
- 인터넷이 끊긴 상태에서 Google 일정이 대기 중이면 계정 표시가 `오프라인 (동기화 대기 N건)`으로 바뀝니다.
- 설정에서 자동 동기화를 5/15/30/60분 또는 사용 안 함으로 지정
- 일정이 많은 캘린더도 모든 페이지를 받은 뒤 반영하며, 조회가 중간에 실패하면 누락 일정을 삭제로 처리하지 않습니다.

계정 표시의 `동기화 대기 N건`을 클릭하면 일정명, 날짜, 대상 캘린더를 확인할 수 있습니다. 재시도는 팝업을 닫고 상단 `G 동기화`를 누릅니다. 대기 일정이 없으면 팝업을 열지 않고 완료 문구만 잠시 표시합니다.

### 캘린더 표시와 수정 권한

- 오른쪽 체크박스로 각 Google 캘린더를 표시하거나 숨깁니다.
- 설정에서 owner/writer 권한 캘린더만 `수정 가능`으로 선택할 수 있습니다.
- 대한민국 휴일 등 구독 캘린더는 항상 읽기 전용입니다.

### 계정 변경과 로그아웃

- 설정의 `Google 계정 변경`: 다른 계정으로 로그인합니다.
- 설정의 `로그아웃`: Google 연결을 해제하고 로컬 저장 상태로 전환합니다.
- 계정별 일정 JSON이 분리되므로 다른 사람의 로컬 일정이 섞이지 않습니다.
- 로그인 후 `로컬 일정 가져오기`로 로그아웃 상태에서 만든 일정 중 원하는 것만 복사할 수 있습니다.

## 9. 검색

1. 상단 검색 아이콘을 누릅니다.
2. 제목 또는 메모 일부를 입력하고 `검색`을 누릅니다.
3. 오늘 기준 ±1년, 과거 1년, 앞으로 1년, 사용자 지정 시작·종료일, 전체 일정 중 검색 기간을 선택합니다.

5. 스크롤 후 `오늘` 버튼을 누르면 오늘 위치로 돌아옵니다.
6. 결과를 선택하면 메인 달력이 해당 날짜로 이동합니다.

## 11. 저장과 백업

데이터와 자동 백업은 `%LOCALAPPDATA%\Onharu`에 통합 저장됩니다.

- 일정: Google 계정별 또는 로그아웃 로컬 JSON
- 설정: 창 위치, 크기, 잠금, 색상, 필터, 정렬 등
- Google refresh token: 현재 Windows 사용자만 풀 수 있도록 암호화
- 자동 백업: ONHARU 로컬 일정만 계정별 하루 1개, 최근 30개
- 외부 자동 백업: 지정 폴더의 `ONHARU-Backups`에 로컬 일정 백업과 최신 설정 파일을 보관합니다. Google 일정은 Google에서 관리하므로 백업하지 않습니다.
- 2.1 최초 실행 전 백업: 기존 설정과 일정 JSON을 `pre-2.1-backup`에 한 번 보존하며 Google 토큰은 복사하지 않습니다.

설정의 `백업 복원`에서는 기본 백업 폴더와 사용자가 지정한 백업 폴더를 구분해 날짜별 백업을 선택할 수 있습니다. 복원 전에는 현재 일정을 별도로 확인하는 것이 안전합니다.

## 12. 문제 해결

### 동기화가 되지 않음

- 인터넷 연결을 확인합니다.
- 계정 표시를 눌러 대기 일정을 확인한 뒤 팝업을 닫고 상단 `G 동기화`를 누릅니다.
- 계속 실패하면 설정에서 Google 계정을 변경하거나 로그아웃 후 다시 연결합니다.

### Google 로그인 창을 닫았는데 로그인 중으로 표시됨

- `로그인 취소`를 누릅니다.
- 아무 작업도 하지 않으면 5분 후 자동 취소됩니다.

### 일정이 수정되지 않음

- 휴일 또는 읽기 전용 캘린더인지 확인합니다.
- 설정의 Google 일정 수정 권한에서 해당 캘린더가 수정 가능인지 확인합니다.
- Google Tasks 원본은 제목/설명/첨부파일 수정이 제한됩니다.

### 바탕화면에서 움직일 수 없음

- 압정 버튼이 `고정됨`이면 눌러 `이동 가능`으로 바꿉니다.
- 상단 버튼이 없는 빈 공간을 드래그합니다.
- 듀얼 모니터에서 노트북 화면만 사용한 뒤 창이 보이지 않으면 트레이 아이콘의 `현재 화면으로 가져오기`를 선택합니다.

### 일정이 사라지거나 파일이 손상된 것 같음

- 즉시 여러 번 저장하지 말고 설정의 백업 복원을 확인합니다.
- 계정을 바꾼 상태라면 원래 Google 계정 또는 로그아웃 로컬 상태로 돌아가 확인합니다.

## 13. 직접 빌드하기

PowerShell에서 소스 폴더로 이동한 뒤 실행합니다.

```powershell
cd .\Onharu_v2.2
.\check-v22.ps1 -Build
```

Windows의 .NET Framework 4.x C# 컴파일러와 WPF 어셈블리를 사용하며 외부 패키지는 사용하지 않습니다.

현재 소스 구조는 다음과 같습니다.

- `App/Program.cs`: 앱 시작과 단일 실행 제어
- `App/MainWindow.cs`: 메인 달력 UI와 화면 동작
- `App/*Window.cs`: 일정, 설정, 검색 등 각 팝업 UI
- `App/ExplorerFramePublisher.cs`, `DesktopActionWindow.cs`: WPF 화면 캐시와 고정 모드 입력 전달
- `ExplorerLayer/DesktopHook.cpp`, `LayerHost.cpp`: Explorer 아이콘 아래 합성과 복구
- `App/UiRound.cs`: 공통 버튼·스크롤 모양
- `App/PlannerItem.cs`, `PlannerSettings.cs`: 일정과 설정 데이터
- `App/RecurrenceService.cs`: 반복 일정 계산
- `App/LocalStorage.cs`: 로컬 저장과 백업
- `App/GoogleApiModels.cs`, `GoogleCalendarService.cs`: Google Calendar 연동

반복 일정 계산 검사는 다음처럼 실행할 수 있습니다.

```powershell
cd .\Onharu_v2.2
.\check-v22.ps1
```

로컬 시험본은 `Tests\LocalTest`에만 생성됩니다.

2.1 개발 소스는 `Onharu_v2.1` 작업 트리에 보존하며, 배포 후보 실행 파일은 `Release\ONHARU-2.2.3\ONHARU.exe`, 설치 파일은 `Release\Installer\ONHARU-2.2.3-Setup.exe`입니다. 2.0은 별도 `Onharu_v2` 폴더에 동결되어 있습니다.

### 설치와 제거

- 설치 위치: `%LOCALAPPDATA%\Programs\ONHARU`
- 제거: Windows 설정의 `설치된 앱` 또는 시작 메뉴의 ONHARU 제거 프로그램
- 제거할 때 일정·설정·Google 연결 정보를 보관할지 선택할 수 있습니다. 기본값은 재설치를 위한 보관이며, `모든 사용자 데이터 삭제`를 확인한 경우에만 `%LOCALAPPDATA%\Onharu` 전체를 삭제합니다.
- 사용자 데이터까지 완전히 지우려면 먼저 일정 내보내기와 백업을 확인한 뒤 해당 폴더를 사용자가 직접 삭제해야 합니다.
- 코드 서명 전 설치 파일은 Windows SmartScreen 경고가 나타날 수 있습니다.

### 일정 가져오기·내보내기

설정의 `일정 가져오기 (온하루)`와 `일정 내보내기 (온하루)`는 ONHARU 로컬 일정만 처리합니다. 파일 안에 Google 일정이 있어도 가져오지 않습니다.

`Excel로 내보내기`는 조회와 정리를 위해 현재 표시된 로컬·Google 전체 일정을 CSV로 저장합니다. D-Day 표시, 반복 방식·종료, 알림 시간도 함께 기록합니다. 이 파일을 ONHARU로 다시 가져오지는 않습니다. Excel에서 제목·메모가 수식으로 실행되지 않도록 `=`, `+`, `-`, `@` 시작 값을 안전한 텍스트로 변환합니다.

- JSON: ONHARU 로컬 일정 백업·이동용
- CSV: 로컬·Google 전체 일정의 Excel 조회용

내보내기는 원본 일정을 변경하지 않습니다. 저장 실패 안내는 5초 동안 표시되며 오류 기록에도 남습니다.
