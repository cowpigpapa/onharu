# 온하루 · ONHARU 사용자 설명서

개발판 화면 하단은 `MADE BY JUAN.HJLEE · ONHARU (step88)`로 표시합니다. 정식 배포부터는 `ver. 1.0.0` 형식의 버전을 사용합니다.

Google Calendar 연결은 Desktop OAuth와 PKCE를 사용합니다. Client Secret은 소스에 넣지 않고 해당 Windows 사용자 환경에만 보관합니다.

온하루는 Windows 바탕화면에 계속 보이는 월간 달력입니다. 하루 종일 일정, 시간별 Todo, 업무/개인 일정과 Google Calendar를 한 화면에서 관리할 수 있습니다.

## 1. 실행하기

1. `Onharu-step88.exe`를 실행합니다.
2. 온하루는 작업표시줄의 일반 창이 아니라 바탕화면 레이어에 표시됩니다.
3. 화면 오른쪽 아래 알림 영역에도 온하루 아이콘이 생깁니다.
4. 종료하려면 달력 오른쪽 위 `×` 또는 트레이 메뉴의 종료를 사용합니다.

개발판은 아직 설치 프로그램과 자동 업데이트를 제공하지 않습니다. EXE 하나로 실행되지만 Google OAuth 보안 구조와 코드 서명이 완료되기 전에는 불특정 다수 배포용이 아닙니다.

파일명이 다른 이전/새 버전 EXE를 함께 실행할 수 없습니다. 온하루는 계정·설정·Google 토큰을 안전하게 관리하기 위해 Windows 사용자당 한 창만 실행됩니다.

## 2. 화면 구성

### 상단

- `온하루 · ONHARU`: 앱 이름과 현재 연월
- 이전/다음 화살표: 월 이동
- 오늘: 이번 달과 오늘 날짜로 복귀
- 압정 버튼: 위치 고정/이동 가능 전환
- `G 연결` 또는 `G 동기화`: Google 로그인과 수동 동기화
- 검색 아이콘: 일정 검색
- 톱니바퀴: 설정
- `×`: 온하루 종료

### 월간 달력

- 토요일 날짜: 파란색
- 일요일 및 국경일 날짜: 빨간색
- 오늘: 옅은 핑크 배경과 `오늘` 문구
- 중요 일정: `★`와 핫핑크 굵은 글씨
- 한 날짜에 최대 6개 일정 표시

### 오른쪽 일정 패널

- 선택한 날짜의 일정을 캘린더/카테고리별 파스텔 카드로 표시합니다.
- 시간 Todo에는 완료 체크박스가 있습니다.
- 패널 왼쪽의 화살표로 접을 수 있으며, 접으면 달력이 넓어집니다.
- 위쪽 Google 계정 표시를 누르면 동기화 대기 일정 목록을 확인할 수 있습니다.

## 3. 창 이동, 크기와 클릭

### 위치 이동

1. 압정 버튼을 눌러 `이동 가능`으로 바꿉니다.
2. 상단의 버튼이 없는 빈 공간을 잡고 이동합니다.
3. 원하는 위치에서 다시 눌러 `고정됨`으로 바꿉니다.

위치, 크기, 고정 상태는 종료 시 저장되어 다음 실행에 복원됩니다.

### 크기 변경

- 오른쪽 아래의 작은 크기 조절 영역을 드래그합니다.
- 다른 가장자리에는 크기 조절 기능이 없습니다.

### 클릭 통과와 편집

- 클릭 통과 상태에서는 온하루 뒤의 바탕화면 폴더와 아이콘을 조작할 수 있습니다.
- 편집 상태에서는 날짜와 일정을 더블클릭할 수 있습니다.
- `Ctrl + Alt + F`로 클릭 통과/편집 상태를 전환할 수 있습니다.

## 4. 일정 등록

날짜의 빈 공간을 더블클릭하거나 오른쪽 패널 아래의 일정 추가 버튼을 누릅니다.

1. 날짜를 확인합니다. 신규 일정은 더블클릭한 날짜로 고정됩니다.
2. 제목을 입력합니다. 제목은 필수입니다.
3. 시간 옵션을 선택합니다.
   - 하루 종일: 완료 체크가 없는 일반 일정
   - 오전/오후 + 1~12시 + 0/15/30/45분: 완료 가능한 Todo
4. 자동 이월을 선택합니다. 기본은 `이월 안 함`입니다.
5. 저장 위치를 선택합니다.
   - 온하루 업무일정/개인일정: 이 PC의 현재 계정 파일에만 저장
   - Google 캘린더 이름: 선택한 Google 캘린더에 동기화
6. 알림, 중요 일정, 반복, 메모를 설정합니다.
7. `일정 저장`을 누르거나 메모 입력 중이 아닐 때 Enter를 누릅니다.

제목이 없으면 별도 경고창 대신 입력창 안에 빨간 안내가 잠시 표시됩니다.

## 5. 일정 수정과 삭제

### 수정

- 달력 칩 또는 오른쪽 패널의 일정을 더블클릭합니다.
- `날짜 변경`을 누르면 팝업 달력이 열립니다.
- 날짜를 선택하고 바깥을 클릭하거나 날짜를 더블클릭하면 적용됩니다.
- 수정창 제목 옆의 배지에서 `온하루 등록`인지 `Google Calendar`인지 확인할 수 있습니다.

Google 휴일 또는 설정에서 수정 불가로 지정한 캘린더는 수정할 수 없습니다. 안내는 클릭한 일정 가까이에 잠시 표시됩니다.

### 반복 일정 수정

반복 종류에 따라 다음 세부 옵션을 선택할 수 있습니다.

- 매일: 매일 또는 평일만
- 매주: 월·화·수·목·금·토·일 복수 선택
- 매월: 같은 날짜, n번째 같은 요일, 마지막 날
- 매년: 같은 월·일
- 모든 반복: 종료일 지정

- 기본: 해당 반복 일정 전체를 수정합니다.
- `이번 일정만 변경` 체크: 선택한 날짜의 일정만 별도로 수정합니다.

### 반복 일정 삭제

삭제 버튼을 누르면 다음 중 하나를 고릅니다.

- 이번 일정만: 선택한 한 번만 삭제
- 이번 일정부터 미래: 이전 기록을 남기고 선택한 날짜부터 제거
- 과거 포함 전체: 과거와 미래를 포함한 반복 전체 삭제

반복이 아닌 일정은 즉시 해당 일정만 삭제합니다.

## 6. Todo 완료와 자동 이월

- 시간이 있는 일정 오른쪽/왼쪽의 체크박스를 누르면 완료됩니다.
- 완료된 일정은 취소선으로 표시됩니다.
- 자동 이월 옵션:
  - 이월 안 함
  - 다음 날
  - 다음 주 같은 요일
  - 다음 평일
- 미완료이며 날짜가 지난 Todo만 이동합니다.

Google Tasks에서 가져온 항목은 Calendar API 제한 때문에 완료 상태가 온하루에만 저장될 수 있습니다.

## 7. 알림

등록/수정창에서 다음 중 선택합니다.

- 없음
- 정시
- 10분 전
- 30분 전
- 하루 전

알림 시각이 되면 모니터 중앙에 온하루 알림이 표시됩니다. 확인하거나 다시 알림을 선택할 수 있습니다. 온하루가 완전히 종료된 동안에는 자체 알림이 표시되지 않습니다. Google 일정의 Google 측 모바일/이메일 알림은 Google Calendar 설정에 따릅니다.

## 8. Google Calendar 연결

### 최초 연결

1. 상단 `G 연결`을 누릅니다.
2. 브라우저에서 Google 계정을 선택하고 권한을 승인합니다.
3. `온하루 연결이 완료되었습니다` 페이지가 보이면 브라우저 창을 닫습니다.
4. 온하루가 내 캘린더, 팀, 가족, 생일, 휴일 등 해당 계정의 목록을 읽습니다.

로그인 브라우저를 닫거나 응답하지 않으면 최대 1분 후 취소 처리됩니다. 기다리는 동안 온하루의 `로그인 취소` 버튼으로 즉시 중단할 수도 있습니다.

### 동기화

- `G 동기화`: 즉시 양방향 동기화
- 성공: `동기화가 완료되었습니다`가 1초 표시
- 실패: 로컬 변경을 보존하고 자동 재시도
- 인터넷이 끊긴 상태에서 Google 일정이 대기 중이면 계정 표시가 `오프라인 (동기화 대기 N건)`으로 바뀝니다.
- 설정에서 자동 동기화를 5/15/30/60분 또는 사용 안 함으로 지정

계정 표시의 `동기화 대기 N건`을 클릭하면 일정명, 날짜, 대상 캘린더를 확인할 수 있습니다. 재시도는 팝업을 닫고 상단 `G 동기화`를 누릅니다. 대기 일정이 없으면 팝업을 열지 않고 완료 문구만 잠시 표시합니다.

### 캘린더 표시와 수정 권한

- 오른쪽 체크박스로 각 Google 캘린더를 표시하거나 숨깁니다.
- 설정에서 owner/writer 권한 캘린더만 `수정 가능`으로 선택할 수 있습니다.
- 대한민국 휴일 등 구독 캘린더는 항상 읽기 전용입니다.

### 계정 변경과 로그아웃

- 설정의 `Google 계정 변경`: 다른 계정으로 로그인합니다.
- 설정의 `로그아웃`: Google 연결을 해제하고 로컬 저장 상태로 전환합니다.
- 계정별 일정 JSON이 분리되므로 다른 사람의 로컬 일정이 섞이지 않습니다.
- 로그인 후 `로컬 일정 가져오기`로 로그아웃 상태에서 만든 일정 중 원하는 것만 복사할 수 있습니다.

## 9. 검색

1. 상단 검색 아이콘을 누릅니다.
2. 제목 또는 메모 일부를 입력하고 `검색`을 누릅니다.
3. 검색 가능한 기간은 오늘 기준 과거 1년부터 미래 1년까지입니다.
4. 기본 목록은 지난 일정이 위, 오늘이 가운데, 예정 일정이 아래에 있습니다.
5. 스크롤 후 `오늘` 버튼을 누르면 오늘 위치로 돌아옵니다.
6. 결과를 선택하면 메인 달력이 해당 날짜로 이동합니다.

- 업무/개인/Google 캘린더 색상 변경
- 두 색상을 체크하여 서로 교환
- 글자 크기
- 진한 일정 칩 또는 파스텔 일정 칩
- 일정 표시 순서: 카테고리별 또는 시간순
- 카테고리 표시 순서
- 주차 표시와 계산 기준
- 음력 표시
- Google 자동 동기화 간격
- Google 캘린더별 수정 가능 여부
- Google 계정 변경/로그아웃
- 로컬 일정 가져오기
- 백업 복원

휴일은 항상 빨간 계열이며 수정할 수 없습니다.

## 11. 저장과 백업

데이터는 `%LOCALAPPDATA%\FamilyPlanner`에 저장됩니다.

- 일정: Google 계정별 또는 로그아웃 로컬 JSON
- 설정: 창 위치, 크기, 잠금, 색상, 필터, 정렬 등
- Google refresh token: 현재 Windows 사용자만 풀 수 있도록 암호화
- 자동 백업: 계정별 하루 1개, 최근 30개

설정의 `백업 복원`에서 날짜별 백업을 선택할 수 있습니다. 복원 전에는 현재 일정을 별도로 확인하는 것이 안전합니다.

## 12. 문제 해결

### 동기화가 되지 않음

- 인터넷 연결을 확인합니다.
- 계정 표시를 눌러 대기 일정을 확인한 뒤 팝업을 닫고 상단 `G 동기화`를 누릅니다.
- 계속 실패하면 설정에서 Google 계정을 변경하거나 로그아웃 후 다시 연결합니다.

### Google 로그인 창을 닫았는데 로그인 중으로 표시됨

- `로그인 취소`를 누릅니다.
- 아무 작업도 하지 않으면 1분 후 자동 취소됩니다.

### 일정이 수정되지 않음

- 휴일 또는 읽기 전용 캘린더인지 확인합니다.
- 설정의 Google 일정 수정 권한에서 해당 캘린더가 수정 가능인지 확인합니다.
- Google Tasks 원본은 제목/설명/첨부파일 수정이 제한됩니다.

### 바탕화면에서 움직일 수 없음

- 압정 버튼이 `고정됨`이면 눌러 `이동 가능`으로 바꿉니다.
- 상단 버튼이 없는 빈 공간을 드래그합니다.

### 일정이 사라지거나 파일이 손상된 것 같음

- 즉시 여러 번 저장하지 말고 설정의 백업 복원을 확인합니다.
- 계정을 바꾼 상태라면 원래 Google 계정 또는 로그아웃 로컬 상태로 돌아가 확인합니다.

## 13. 직접 빌드하기

PowerShell에서 소스 폴더로 이동한 뒤 실행합니다.

```powershell
cd .\Step2-Refactoring\Source
.\build.ps1 -OutputName Onharu-test.exe
```

Windows의 .NET Framework 4.x C# 컴파일러와 WPF 어셈블리를 사용하며 외부 패키지는 사용하지 않습니다.

현재 소스 구조는 다음과 같습니다.

- `Step2-Refactoring/Source/Program.cs`: 앱 시작과 단일 실행 제어
- `Step2-Refactoring/Source/MainWindow.cs`: 메인 달력 UI와 화면 동작
- `Step2-Refactoring/Source/*Window.cs`: 일정, 설정, 검색 등 각 팝업 UI
- `Step2-Refactoring/Source/DesktopLayer.cs`: Windows 바탕화면 레이어와 단축키
- `Step2-Refactoring/Source/UiRound.cs`: 공통 버튼·스크롤 모양
- `Step2-Refactoring/Source/PlannerItem.cs`, `PlannerSettings.cs`: 일정과 설정 데이터
- `Step2-Refactoring/Source/RecurrenceService.cs`: 반복 일정 계산
- `Step2-Refactoring/Source/LocalStorage.cs`: 로컬 저장과 백업
- `Step2-Refactoring/Source/GoogleApiModels.cs`, `GoogleCalendarService.cs`: Google Calendar 연동

반복 일정 계산 검사는 다음처럼 실행할 수 있습니다.

```powershell
cd .\Step2-Refactoring\Source
.\recurrence-check.ps1
```

### 일정 내보내기

설정의 `일정 내보내기`에서 현재 계정에 표시된 일정을 저장할 수 있습니다.

- JSON: 온하루 데이터와 동기화 정보를 포함한 전체 보관용
- CSV: Excel 등에서 목록을 확인하고 정리하는 용도
- ICS: Google Calendar, Outlook 등 다른 캘린더로 가져오는 용도

내보내기는 원본 일정을 변경하지 않습니다. 저장 실패 안내는 5초 동안 표시되며 오류 기록에도 남습니다.
