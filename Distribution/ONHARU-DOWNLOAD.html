2.1·2.2.0 사용자는 2.2.1을 한 번 직접 설치해 주세요.

이전 버전의 자동 업데이트 연결 문제를 고친 안정화 버전입니다. 2.2.1을 설치한 뒤부터는 앱의 사용자 승인형 자동 업데이트를 정상적으로 사용할 수 있으며 기존 일정·설정·Google 연결·일기·시간표 데이터는 유지됩니다.

Windows에서 ‘알 수 없는 게시자’가 표시될 수 있습니다.

현재 설치 파일에는 유료 코드 서명이 적용되지 않았습니다. 반드시 이 페이지에서 받은 공식 파일인지 먼저 확인하세요.

  1. 파일 이름이 ONHARU-2.2.1-Setup.exe인지 확인합니다.
  2. Windows 보호 화면에서 추가 정보를 누르고, 파일 출처가 맞을 때만 실행을 선택합니다.
  3. 더 정확히 확인하려면 PowerShell에서 Get-FileHash .\ONHARU-2.2.1-Setup.exe를 실행해 위 SHA-256 값과 비교합니다.

일정·설정·연동 정보와 자동 백업은 %LOCALAPPDATA%\Onharu에 저장됩니다. 업데이트 후에도 유지됩니다. 설치부터 차근차근 보려면 사용설명서를 확인하세요.
