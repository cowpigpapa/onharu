# ONHARU 2.2.3

ONHARU 2.2.3은 달력 기간 선택과 알림 설정을 단순화하고, 최근 화면·입력 회귀를 보완한 안정화 버전입니다.

## 주요 변경

- 상단 기간 버튼에서 1~6주를 직접 선택하고, 월 전체는 달력에 맞춰 4~6주를 자동 표시
- 1~2주 보기에서는 오늘을 첫째 줄, 3~6주 보기에서는 둘째 줄에 배치
- 알림 사용 여부와 알림 표시 위치를 하나의 설정 카드로 통합
- 알림을 끄면 기존 일정의 알림·소리도 함께 중지
- 중요한 날을 날짜 옆의 간결한 별 표시로 변경
- 오른쪽 상세 일정의 카테고리별·시간순 정렬을 메인 달력과 독립적으로 선택
- 주 범위 선택 팝업의 위치·크기·테마를 ONHARU 스타일로 정리
- 설정에서 더 이상 사용하지 않는 달력 범위와 닫기 동작 옵션 제거
- 신규 설치에서 샘플 일정이 자동 생성되던 문제와 프리셋 대표색 반영 오류 수정

## 설치

- 기존 ONHARU 설치판 위에 덮어쓰면 일정·설정·Google 연결·일기·시간표 데이터가 유지됩니다.
- 사용자 승인형 자동 업데이트는 설치 파일의 SHA-256을 확인한 뒤에만 실행합니다.
- Windows 코드 서명은 아직 적용되지 않아 SmartScreen 안내가 나타날 수 있습니다.

## 확인 예정

- 서로 다른 배율을 쓰는 다중 모니터 이동은 실제 혼합 DPI 장비에서 추가 검증합니다.
