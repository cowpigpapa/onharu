# ONHARU 2.2.4

ONHARU 2.2.4는 일정 카드 조작과 고정 화면 입력을 확장하고, 색상 대비와 상세 패널의 완성도를 높인 안정화 업데이트입니다.

## 일정과 상세 패널

- 로컬·Google 일정을 달력에서 드래그해 날짜를 변경하고 `Ctrl + 드래그`로 복사
- 오른쪽 상세 카드의 순서를 드래그로 변경하고 D-Day·기념일 카드도 같은 방식으로 정렬
- 중요 일정은 항상 위에 유지하고 일반 일정끼리만 순서 변경
- 일반 일정·시간순·D-Day·기념일 카드를 제목 클릭으로 접기·펼치기
- Explorer 고정 상태에서도 일반 상세 카드 접기·펼치기 지원
- 접힌 카드의 글자 잘림을 막도록 공통 내부 여백 보완
- 모든 스크롤바의 트랙은 중립적으로, 손잡이는 프리셋 대표색의 파스텔 톤으로 통일

## 색상과 가독성

- 대표색이 헤더·버튼·카드에 과도하게 반복되지 않도록 색상 사용 비율 정리
- 파스텔은 중립면 중심, 블랙은 네온·발광을 배제하고 흰 글씨 대비 확보
- 중요 일정의 사용자 글씨색도 WCAG 4.5:1 대비를 만족하지 않으면 자동 보정
- 다섯 번째 프리셋 명칭을 `앰버선셋`으로 통일

## 안정성 확인

- 100%↔125% 배율과 서로 다른 해상도의 다중 모니터 이동 정상 확인
- 이동·고정 전환 후 위치와 크기 유지 확인
- 1920×1080 125% 화면에서 상단 필수 조작부 잘림 없음 확인
- 전체 자동 품질 검사 통과

## 설치

- 기존 ONHARU 위에 덮어쓰면 일정·설정·Google 연결·일기·시간표 데이터가 유지됩니다.
- Windows 코드 서명은 아직 적용되지 않아 SmartScreen 안내가 나타날 수 있습니다.
