# ONHARU 2.1.0

ONHARU는 Windows 바탕화면과 아이콘 사이에 표시되는 데스크톱 달력입니다.

## 주요 변경

- V1 기능과 디자인을 기반으로 한 공식 2.1 달력
- Google Calendar 로그인·동기화 및 미동기화 일정 관리
- 로컬 일정, 반복 일정, 할 일, 알림, 검색, 가져오기·내보내기
- 별도 D-Day와 기념일 카드 및 기념일 전용 등록·수정
- 월 전체/사용자 지정 주 범위와 이번 주 위치 설정
- Explorer 아이콘 아래 고정과 일반 WPF 위치 조정 모드
- 작은 노트북, DPI, 다중 모니터 위치 보정
- 독립 일기 작성창과 검색 가능한 일기장 리더
- Google Calendar 일정과 분리된 선택형 Google Tasks 동기화
- JSON 백업, ICS 달력 교환, 전체 일정 Excel CSV 보고서
- Parse.bot 개인 API 키를 사용하는 선택형 KBO 경기 일정
- KBO 4주/월간 보기, 최대 2개 응원팀, 경기 선택 후 로컬 야구 일정 등록
- 메인 달력의 설정 기간/임시 월간 보기 전환

## 전환 안정화

고정에서 이동 가능으로 바뀔 때 WPF 창을 투명하게 먼저 DWM 합성 경로에 참여시킨 뒤, 다음 렌더 프레임에서 정상 투명도 복원과 Explorer 프레임 해제를 교대하도록 개선했습니다. 실제 UI Dispatcher 왕복 1,000회(렌더 전환 2,000회) 시험에서 실패 0건과 정상 종료를 확인했습니다.

## 설치 및 실행

- 설치판은 코드 서명이 없어 Windows SmartScreen의 `알 수 없는 게시자` 안내가 나타날 수 있습니다.
- Portable ZIP은 압축을 푼 뒤 `ONHARU.exe`를 실행합니다. 같은 폴더의 LayerHost EXE와 DesktopHook DLL을 분리하거나 삭제하면 바탕화면 고정 기능이 동작하지 않습니다.
- 일정·설정·연동 정보와 자동 백업은 `%LOCALAPPDATA%\Onharu`에 저장됩니다.

2.1 최종 빌드는 자동 품질 검사 13종, 격리 설치·제거, 기존 설치 덮어쓰기와 설치 파일 해시 검증을 통과했습니다.
