온하루의 새로운 소식.

버전별로 추가된 기능과 중요한 변경 사항을 확인하세요.

ONHARU 2.1.0

Windows 바탕화면 달력의 기능과 안정성을 크게 확장한 정식 버전

현재 버전

새로운 기능

  • Google Calendar와 로컬 일정을 한 화면에서 관리
  • 일정·Todo 완료 표시, 알림과 고급 반복 일정
  • D-Day·기념일·일기장·독립 시간표
  • JSON 백업, ICS 가져오기·내보내기, Excel CSV 교환
  • 선택형 Google Tasks 동기화
  • 개인 API 키를 사용하는 KBO 4주·월간 일정과 선택 등록
  • 달력 인쇄와 선택 일정 안전 삭제

화면과 사용성

  • 1~6주와 임시 월간 보기, 시작 요일과 이번 주 위치 설정
  • 바탕화면 아이콘 아래 고정 모드와 위치 조정 모드
  • 작은 노트북, 고해상도, 다중 모니터 위치 복구 개선
  • 공통 팝업과 스크롤, 일정 등록·수정 화면 정돈

데이터와 안정성

  • Google 동기화 실패 일정의 로컬 대기와 재시도
  • 일정 선택 삭제 전 자동 안전 백업
  • Google 원본을 변경하지 않는 ICS·CSV 가져오기
  • 인증 정보의 Windows 사용자 암호화와 오류 기록 마스킹

설치 안내

  • Windows 10·11 64비트 권장
  • 미서명 설치판은 Windows의 ‘알 수 없는 게시자’ 안내가 표시될 수 있음
  • 일정·설정·연동 정보와 자동 백업은 %LOCALAPPDATA%\Onharu에 저장
