온하루의 새로운 소식.

버전별로 추가된 기능과 중요한 변경 사항을 확인하세요.

ONHARU 2.2.0

2.1의 안정성을 유지하면서 화면과 색상 체계를 다듬은 디자인 업데이트

현재 버전

디자인과 사용성

  • 파스텔·블랙 두 가지 디자인 스킨과 상단 빠른 전환
  • 일정 배경·글자·체크박스·오른쪽 카드의 공통 색상 규칙
  • 다섯 가지 색상 프리셋과 사용자 색상 저장·교환·초기화
  • 달력 기간, 이동·고정, 스포츠 보기의 공통 슬라이딩 버튼
  • 시간표·일기장·KBO 창의 제목, 아이콘과 대표 버튼 통일

기능과 안정성

  • Google Calendar·선택형 Google Tasks 동기화
  • 로컬 일정, D-Day, 기념일, 일기장과 독립 시간표
  • JSON·ICS·CSV 교환과 이메일 백업
  • KBO 경기 일정 보기 크기 저장과 다음 실행 시 복원
  • 팝업 중복 및 이동·고정 전환 충돌 방지 정책
  • 사용자 승인형 자동 업데이트와 설치 파일 SHA-256 검증

설치 안내

  • Windows 10·11 64비트 권장
  • 기존 ONHARU 위에 설치해 일정·설정·연결 정보를 유지하며 업데이트 가능
  • 미서명 설치판은 Windows의 ‘알 수 없는 게시자’ 안내가 표시될 수 있음
  • 일정·설정·연동 정보와 자동 백업은 %LOCALAPPDATA%\Onharu에 저장
