ONHARU 2.2.4

일정 카드 조작과 색상 가독성을 보완한 안정화 업데이트

현재 버전

주요 변경

  • 로컬·Google 일정 드래그 이동과 Ctrl+드래그 복사
  • 오른쪽 상세 카드 순서 변경과 일반·D-Day·기념일 접기/펼치기
  • 고정 상태의 상세 카드 입력과 공통 내부 여백 보완
  • 전역 ONHARU 스크롤바와 프리셋 파스텔 손잡이 적용
  • 중요 일정과 사용자 색상의 WCAG 대비 자동 보정
  • 100%↔125% 및 서로 다른 해상도의 혼합 DPI 실기기 검증 완료

ONHARU 2.2.3

달력 기간 선택과 알림 설정을 단순화한 안정화 업데이트

이전 버전

주요 변경

  • 상단 기간 버튼에서 1~6주를 직접 선택하고 월 전체는 4~6주 자동 표시
  • 알림 사용 여부와 알림 표시 위치를 하나의 설정 카드로 통합
  • 중요한 날 별 표시와 오른쪽 상세 일정의 독립 정렬 보완
  • 주 범위 선택 팝업의 위치·크기·테마를 ONHARU 스타일로 정리
  • 신규 설치 샘플 일정 생성 및 프리셋 대표색 반영 오류 수정

확인 예정

  • 서로 다른 배율을 쓰는 다중 모니터 이동은 실제 혼합 DPI 장비에서 추가 검증

ONHARU 2.2.1

자동 업데이트와 Google 연결 오류 안내를 보완한 안정화 패치

이전 버전

수정 사항

  • .NET Framework 환경에서 GitHub 접속에 TLS 1.2를 사용해 자동 업데이트 확인 실패 수정
  • 앱 시작 시 자동 업데이트 확인을 Google 초기 동기화보다 먼저 실행하도록 순서 분리
  • Google 인증 만료·취소와 네트워크 장애를 구분해 재로그인 필요 여부 안내
  • 인증 오류 안내와 로그에서 토큰·개인정보 마스킹 유지

꼭 확인해 주세요

  • ONHARU 2.1·2.2.0 사용자는 2.2.1 설치판을 최초 한 번 수동 설치해야 함
  • 2.2.1 이후 버전부터 사용자 승인형 자동 업데이트 정상 사용 가능
  • 기존 일정·설정·Google 연결·일기·시간표 데이터 유지

ONHARU 2.2.0

2.1의 안정성을 유지하면서 화면과 색상 체계를 다듬은 디자인 업데이트

이전 버전

디자인과 사용성

  • 파스텔·블랙 두 가지 디자인 스킨과 상단 빠른 전환
  • 다섯 가지 색상 프리셋과 사용자 색상 저장·교환·초기화
  • 달력 기간, 이동·고정과 주요 부가기능의 공통 화면 규칙
  • 메인 달력·설정·오른쪽 카드의 일관된 색상과 읽기 쉬운 글자 대비

기능과 안정성

  • JSON·ICS·CSV 교환과 이메일 백업
  • 사용자 승인형 자동 업데이트와 설치 파일 SHA-256 검증
  • KBO 경기 일정 보기 크기 저장과 다음 실행 시 복원
  • 팝업 중복 및 이동·고정 전환 충돌 방지
