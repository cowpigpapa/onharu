개인정보처리방침

시행일: 2026년 8월 23일 · 적용 버전: ONHARU 2.2.5

ONHARU의 로컬 일정·일기·설정은 사용자의 Windows PC에 저장됩니다. Google 연동을 선택한 경우에만 승인한 Google 데이터가 Google API를 통해 처리되며, 사용자가 메일 백업을 직접 요청한 경우에만 발송 중계 서버가 첨부 파일과 수신 Gmail을 일시 처리합니다.

1. 처리하는 정보와 목적

구분처리 정보목적
로컬 기능일정, 할 일, 기념일, 일기, 시간표, 설정, 백업달력 표시, 알림, 검색, 백업·복원
Google Calendar캘린더 목록과 일정의 제목, 시간, 설명, 반복, 알림 등선택한 Google 캘린더 조회·생성·수정·삭제와 동기화
Google Tasks할 일 목록, 제목, 날짜, 메모, 완료 상태Google Tasks 표시와 사용자가 요청한 생성·수정·삭제·완료 동기화

오류 기록오류 시각, 동작 위치, 기술적 오류 내용앱 오류 진단. 이메일 주소와 토큰 형태의 문자열은 기록 전에 마스킹

2. 저장 위치와 보유 기간

일정·설정·연동 정보와 자동 안전 백업은 사용자의 PC 내 %LOCALAPPDATA%\Onharu에 저장됩니다. Google OAuth 갱신 토큰은 Windows 현재 사용자 계정으로 암호화됩니다. 사용자가 메일 백업을 요청한 경우 첨부 파일과 수신 Gmail은 AWS 서울 리전의 발송 중계에서 전송을 완료하는 동안만 처리하며 별도 일정 저장소에 보관하지 않습니다. 그 밖의 로컬 데이터는 자체 서버로 전송하지 않습니다. PC의 데이터는 사용자가 앱의 데이터 삭제 기능을 실행하거나 해당 폴더를 직접 삭제할 때까지 보관됩니다.

3. 제3자 제공과 외부 서비스

ONHARU는 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. Google 연동 시 데이터는 기능 수행을 위해 Google Calendar API 및 Google Tasks API와 송수신되며, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

4. Google API 데이터의 이용 제한

Google API에서 받은 정보는 사용자가 요청한 달력·할 일 기능을 제공하고 개선하는 용도로만 사용합니다. 광고, 신용 판단, 사용자 추적, 제3자 판매에 사용하지 않으며 사람이 임의로 열람하지 않습니다.

5. 사용자의 선택과 삭제

  • Google 연동은 선택 사항이며, 연동하지 않아도 로컬 기능을 사용할 수 있습니다.
  • 설정의 Google 로그아웃으로 ONHARU에 저장된 인증 정보를 삭제할 수 있습니다.
  • Google 계정의 보안 설정에서 ONHARU의 접근 권한을 언제든 철회할 수 있습니다.
  • 설정의 로컬 데이터 삭제 기능으로 일정·설정·인증 정보를 삭제할 수 있습니다. 제거 프로그램만 실행하면 재설치를 위해 사용자 데이터가 남을 수 있습니다.
  • 삭제 전 필요한 일정은 JSON 또는 CSV로 내보낼 수 있습니다.

6. 보호 조치

인증 토큰은 Windows 데이터 보호 기능으로 현재 사용자만 복호화할 수 있게 저장합니다. 읽기 전용 Google 캘린더는 앱에서도 수정할 수 없도록 제한하고, 오류 기록에는 이메일과 인증 정보가 남지 않도록 마스킹합니다.

7. 아동의 개인정보

ONHARU는 연령 정보를 수집하지 않으며 아동을 대상으로 개인정보를 고의로 수집하지 않습니다.

처리 항목이나 기능이 달라지면 시행일과 변경 내용을 이 페이지에 공개합니다. 개인정보 관련 문의는 support@onharu.app 또는 ONHARU 지원·문의 페이지를 이용해 주세요. 개인정보처리자: ONHARU 개발자 JUAN.HJLEE.
