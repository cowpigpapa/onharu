# ONHARU 2.2.2

ONHARU 2.2.2는 스킨·색상 일관성과 메인 헤더·부가 기능 UI를 보완한 품질 개선 버전입니다.

## 주요 변경

- 파스텔·블랙 2종 스킨과 추천 팔레트 정비
- 달력·설정·오른쪽 일정 카드의 배경·글자 색 대비 통일
- 선택 날짜·주 범위·오늘·슬라이딩 버튼 상태색 정리
- 메인 헤더 아이콘·이동/고정·패널 접기 배치 보완
- 시간표·일기장·KBO 경기 일정 팝업 디자인 통일
- 음력·24절기·오늘 표시의 테마별 가독성 개선
- 기존 설정이 없는 신규 설치의 기본 보기를 4주로 정리

## 설치

- 기존 ONHARU 설치판 위에 덮어쓰면 일정·설정·Google 연결·일기·시간표 데이터가 유지됩니다.
- 2.2.1 사용자는 시작 시 자동 업데이트 안내를 받을 수 있습니다.
- Windows 코드 서명은 아직 적용되지 않아 SmartScreen 안내가 나타날 수 있습니다.

## 후속 확인

- 서로 다른 DPI와 125% 배율의 다중 모니터 이동은 실제 장비에서 확인한 뒤 2.2.3에서 필요한 보정을 진행합니다.
