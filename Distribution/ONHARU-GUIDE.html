ONHARU 다운로드자주 묻는 질문
설치화면이동·고정일정설정독립 아이콘Google백업문제 해결
1

설치와 첫 실행

  1. 다운로드 페이지에서 권장 표시가 있는 설치판을 받습니다.
  2. Windows 보호 화면에서는 공식 파일명을 확인하고 추가 정보 → 실행을 선택합니다.
  3. 시작 메뉴에서 ONHARU를 실행하고 위치와 크기를 맞춘 뒤 고정합니다.
알 수 없는 게시자
현재 유료 코드 서명이 없습니다. onharu.app에서 받은 파일인지 확인하고 SHA-256 값도 비교할 수 있습니다.
2

달력 화면 한눈에 보기

상단 조작부

오늘, 이전·다음, 검색, 인쇄, 설정, 스킨과 이동·고정을 제어합니다.

가운데 달력

1~6주 또는 월 전체를 표시하고 날짜별 일정을 보여줍니다.

오른쪽 필터

업무·개인·야구·D-Day·기념일과 Google 달력을 켜고 끕니다.

오른쪽 상세

선택 날짜·이번 주·다음 주를 카테고리순 또는 시간순으로 봅니다.

업무·개인 필터는 일정을 삭제하지 않습니다. 숨겼다가 언제든 다시 켤 수 있습니다.

3

바탕화면에 배치하고 고정하기

이동

일반 창처럼 끌어서 옮기고 가장자리에서 크기를 바꿉니다. 모니터나 표시 배율이 바뀌면 다시 맞춥니다.

고정

달력이 바탕화면 아이콘 아래 레이어로 들어갑니다. 달력과 바탕화면 아이콘을 모두 사용할 수 있습니다.

  • 주 보기 버튼을 다시 누르면 1~6주 선택
  • 월 전체는 필요한 4~6행 자동 계산
  • 화면 밖으로 나가면 알림 영역 메뉴의 화면에 보이기
4

일정과 할 일 등록하기

  1. 날짜를 두 번 누르거나 + 이 날짜에 추가를 선택합니다.
  2. 제목, 날짜·시간, 업무·개인 또는 Google 저장 위치를 고릅니다.
  3. 필요하면 중요, D-Day, 반복, 알림, 메모를 지정하고 저장합니다.
Todo·자동 이월

완료 체크와 다음 날·다음 주·다음 평일 이월을 지원합니다.

반복·연속 일정

매일·매주·매월 반복과 여러 날 일정을 지원합니다.

D-Day·기념일

남은 날짜와 매년 돌아오는 날을 별도 카드로 관리합니다.

드래그 이동

편집 가능한 일정은 날짜 사이로 이동할 수 있습니다.

5

설정 항목 자세히 보기

디자인·색상파스텔·블랙 스킨, 추천 프리셋, RGB 조절과 내 설정 저장
달력 내 표시주차, 음력, 24절기와 상단 기능 아이콘 표시
등록 카테고리업무·개인·야구 중 새 일정에 사용할 카테고리 선택. 기존 데이터는 유지
화면과 동작시작 요일, 쉬는 날, 완료 표현, 시작 화면, 오늘·선택 날짜와 글자 크기
새 일정 기본값기본 달력, 하루종일·시간, 시작 시각과 기본 알림
Google·알림표시·수정할 캘린더, Tasks, 알림 소리·방해 금지 시간·표시 모니터
데이터 관리JSON·ICS·CSV 가져오기·내보내기, 백업 복원과 선택 삭제

변경 후에는 마지막의 설정 저장을 눌러 적용합니다.

6

독립 아이콘과 부가 기능

▦시간표요일·교시별 시간표를 독립 창에서 편집합니다.
✎일기장날짜별 일기를 쓰고 읽는 로컬 기록입니다.
⚾프로야구KBO 경기 중 원하는 경기만 로컬 또는 Google에 등록합니다.
⌕검색일정을 찾고 해당 날짜로 바로 이동합니다.
▣인쇄현재 달력을 미리 보고 실제 프린터로 출력합니다.
⚙설정화면·일정·연결·알림·데이터를 한곳에서 관리합니다.
7

Google Calendar와 Tasks

  1. 오른쪽 Google 영역의 Login을 누르고 계정을 선택합니다.
  2. 권한 안내를 확인하고 필요한 접근만 승인합니다.
  3. 설정에서 표시·수정할 캘린더를 고르고, 필요할 때만 Tasks를 켭니다.
  • Google 없이도 로컬 업무·개인 일정 사용 가능
  • 읽기 전용 캘린더는 표시만 가능
  • 동기화 실패 변경은 보존 후 다시 시도
8

백업과 데이터 위치

JSON

ONHARU 로컬 일정의 정확한 백업·복원

ICS

다른 달력 프로그램과 일정 교환

CSV

Google 포함 전체 일정을 Excel에서 정리

자동 백업

중요한 삭제·복원 전 안전 사본 생성

사용자 데이터는 %LOCALAPPDATA%\Onharu에 저장되며 업데이트 후에도 유지됩니다.

9

문제가 생겼을 때

달력이 안 보임알림 영역 ONHARU 메뉴에서 화면에 보이기
옮길 수 없음상단의 고정을 눌러 이동 상태로 전환
일정이 사라져 보임오른쪽 업무·개인·Google 필터 확인
Google 실패인터넷과 로그인을 확인하고 동기화 재시도

해결되지 않으면 버전, Windows 버전, 재현 순서와 개인정보를 가린 화면을 support@onharu.app으로 보내주세요.
