# ONHARU 2.2.5

ONHARU 2.2.5는 고정 화면의 입력, 블랙 스킨의 가독성, 상세 패널의 흔들림을 바로잡은 안정화 업데이트입니다.

## 고정 화면에서 동작하지 않던 조작

- 오른쪽 패널의 `온하루 일정`·`Google` 그룹 접기·펼치기가 고정 상태에서 동작하지 않던 문제 수정
- 미완료 To-Do 카드의 일정 이름을 두 번 눌러 수정 창을 여는 동작이 고정 상태에서 동작하지 않던 문제 수정
- 알람 창이 고정 상태에서 나타나지 않던 문제 수정
- 기간 스위치를 빠르게 두 번 누르면 목록이 닫히지 않던 문제 수정
- 접기·펼치기 화살표의 누를 수 있는 범위를 넓혀 잡기 쉽게 조정

## 블랙 스킨 가독성

- 달력의 `+N개 더보기` 팝업에서 일정 글자가 보이지 않던 문제 수정. 팝업은 밝은 바탕이므로 팝업 전용 색으로 계산합니다.
- 시간순·미완료 보기에서 카드 배경이 과하게 강조되던 문제 수정
- 메인 달력 배경을 카드 색과 맞춰 정돈

## 상세 패널과 헤더

- 카테고리순·시간순·미완료를 오갈 때 날짜 제목과 도구 아이콘이 위아래로 흔들리던 문제 수정
- 기념일 카드를 접고 펼 때 `+` 버튼이 움직이던 문제 수정
- `오늘`·`이번 주`·`다음 주`와 세 보기의 날짜 표기를 하나의 양식으로 통일
- 상단 기능 아이콘 줄이 창 조작 버튼 왼쪽에 고정되고 아이콘 수에 따라 왼쪽으로 늘어나도록 정리

## 입력 편의

- 알람의 시각·타이머, 시간표의 시작 시각을 가운데 정렬
- 수기로 입력하는 칸은 누르는 즉시 기존 값이 선택되어 바로 새 값을 칠 수 있습니다. 메모와 일기 본문은 제외합니다.
- 미완료 목록 제목에 연도를 표시

## 접근성과 정리

- 상단 아이콘 버튼과 창 조작 버튼에 이름을 부여해 화면 낭독기에서 읽히도록 보완
- 동작하지 않던 내부 분기와 쓰이지 않는 정의를 정리
- 전체 자동 품질 검사 18개 통과

## 설치

- 기존 ONHARU 위에 덮어쓰면 일정·설정·Google 연결·일기·시간표 데이터가 유지됩니다.
- Windows 코드 서명은 아직 적용되지 않아 SmartScreen 안내가 나타날 수 있습니다. `SHA256SUMS.txt`로 파일을 확인할 수 있습니다.
