서비스 이용약관

시행일: 2026년 8월 23일 · 적용 대상: ONHARU 2.1 및 onharu.app

ONHARU의 기본 기능은 현재 무료로 제공됩니다. 회원가입은 없으며 로컬 기능은 사용자의 PC에서 동작합니다. Google 및 프로야구 기능은 이용자가 선택해 연결하는 외부 서비스입니다. 향후 일부 기능에는 요금이 적용될 수 있습니다.

제1조 목적과 적용 범위

이 약관은 ONHARU 개발자 JUAN.HJLEE(이하 “운영자”)가 제공하는 ONHARU Windows 소프트웨어, 공식 웹사이트 onharu.app, 다운로드와 지원 서비스(이하 통칭 “서비스”)의 이용 조건을 정합니다. 이용자가 ONHARU를 내려받아 설치하거나 사용하면 이 약관에 동의한 것으로 봅니다. 동의하지 않으면 설치 또는 사용을 중단해 주세요.

제2조 서비스 내용

  1. Windows 바탕화면 달력, 로컬 일정, Todo, 반복 일정, D-Day, 기념일, 일기, 시간표, 검색과 백업 기능
  2. 이용자가 선택한 Google Calendar 및 Google Tasks 연동
  3. 이용자가 직접 발급한 API 키를 사용하는 선택형 프로야구 일정 조회
  4. 공식 설치 파일, 릴리스 정보, FAQ와 이메일 지원

현재 기본 기능은 무료로 제공되지만, 운영자는 향후 Google 연동을 포함한 일부 기능을 유료로 전환하거나 별도의 유료 기능·요금제를 추가할 수 있습니다. 유료 적용 대상, 가격, 시행일, 결제·해지·환불 조건은 적용 전에 공식 사이트 또는 프로그램에서 별도로 안내합니다. 이용자의 명시적인 구매 및 결제 동의 없이 요금을 청구하지 않습니다.

제3조 이용 환경과 이용자의 책임

  1. 이용자는 지원되는 Windows 환경과 공식 배포처에서 받은 파일을 사용해야 합니다.
  2. 이용자는 중요한 일정과 일기를 정기적으로 백업하고, 내보낸 파일을 안전하게 보관해야 합니다.
  3. Google 계정, API 키와 인증 정보는 본인이 관리하며 타인에게 공개해서는 안 됩니다.
  4. 서비스를 법령 위반, 타인의 권리 침해, 시스템 공격·우회·악성코드 배포 목적으로 사용할 수 없습니다.

제4조 외부 서비스

Google Calendar, Google Tasks와 프로야구 일정 제공자는 ONHARU와 별개의 서비스입니다. 해당 기능에는 각 제공자의 약관·정책·API 제한·요금 또는 사용량 기준이 적용됩니다. 외부 서비스의 장애, 정책 변경, API 중단이나 데이터 형식 변경으로 일부 기능이 제한될 수 있습니다. ONHARU는 이용자가 요청하지 않은 Google 원본 데이터를 임의로 변경하지 않도록 설계합니다.

제5조 데이터와 개인정보

일정·설정·연동 정보와 자동 백업은 이용자의 PC 내 %LOCALAPPDATA%\Onharu에 저장됩니다. Google 연동을 선택한 경우에만 승인된 범위의 데이터가 Google API와 송수신됩니다. 자세한 처리 기준은 개인정보처리방침을 따릅니다.

제6조 지식재산권과 이용 허락

ONHARU의 프로그램, 디자인, 문서, 로고와 웹사이트 콘텐츠에 관한 권리는 운영자 또는 정당한 권리자에게 있습니다. 운영자는 개인과 조직에 ONHARU를 정상적으로 설치하고 사용할 수 있는 비독점적·양도 불가능한 이용 권한을 부여합니다. 법령이 허용하는 경우를 제외하고 프로그램이나 배포 파일을 무단 판매, 재배포, 임대하거나 출처를 오인하게 해서는 안 됩니다.

제7조 서비스 변경과 중단

운영자는 기능 개선, 보안, 외부 API 변경 또는 운영상 필요에 따라 서비스를 변경하거나 일부 기능을 중단할 수 있습니다. 이용자에게 중요한 변경은 가능한 범위에서 공식 사이트의 릴리스 노트 또는 공지로 안내합니다. 무료 서비스의 성격상 특정 기능이나 지원 기간이 영구히 유지됨을 보장하지 않습니다.

제8조 보증과 책임의 범위

  1. 운영자는 서비스의 안정성과 데이터 보호를 위해 합리적으로 노력하지만, 모든 환경에서 오류가 없거나 항상 중단 없이 동작함을 보증하지 않습니다.
  2. 이용자의 조작, 비공식 배포본, 운영체제·외부 서비스 장애, 기기 고장 또는 백업 미실시로 발생한 손해에 대해서는 운영자의 고의 또는 중대한 과실이 없는 한 책임을 지지 않습니다.
  3. 이 조항은 관련 법령에 따라 배제하거나 제한할 수 없는 소비자의 권리와 운영자의 책임을 제한하지 않습니다.

제9조 이용 종료

이용자는 언제든 프로그램을 제거해 이용을 종료할 수 있습니다. 프로그램 제거 후에도 재설치를 위해 사용자 데이터가 남을 수 있으므로 완전 삭제를 원하면 앱의 데이터 삭제 기능 또는 안내된 저장 폴더를 확인해 주세요. Google 계정 설정에서 ONHARU 접근 권한도 별도로 철회할 수 있습니다.

제10조 약관 변경

운영자는 관련 법령을 위반하지 않는 범위에서 약관을 변경할 수 있습니다. 변경 내용과 시행일은 원칙적으로 시행 7일 전 공식 사이트에 공개하고, 이용자에게 불리한 중요한 변경은 가능한 범위에서 30일 전에 알립니다. 법령·보안상 긴급한 변경은 먼저 적용한 뒤 지체 없이 안내할 수 있습니다.

제11조 준거법과 분쟁 해결

이 약관은 대한민국 법령을 따릅니다. 분쟁이 발생하면 운영자와 이용자는 성실히 협의하며, 해결되지 않는 경우 관련 법령이 정한 관할 법원 또는 분쟁조정 절차를 이용할 수 있습니다.
