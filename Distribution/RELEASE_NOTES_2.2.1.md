# ONHARU 2.2.1

ONHARU 2.2.1은 자동 업데이트와 Google 연결 오류 안내를 보완한 안정화 패치입니다.

## 수정 사항

- .NET Framework 환경에서 GitHub 접속에 TLS 1.2를 명시해 자동 업데이트 확인 실패 수정
- 앱 시작 시 자동 업데이트를 Google 초기 동기화보다 먼저 확인하도록 순서 분리
- Google 인증 만료·취소와 네트워크 장애를 구분해 재로그인 필요 여부 안내
- 인증 오류 안내에 토큰과 개인정보를 노출하지 않도록 기존 로그 마스킹 유지

## 설치 안내

- ONHARU 2.1·2.2.0 사용자는 구형 업데이트 연결 문제 때문에 2.2.1 설치판을 최초 한 번 수동 설치해야 합니다.
- 2.2.1 이후 버전부터 GitHub 자동 업데이트를 정상 사용할 수 있습니다.
- 기존 일정·설정·Google 연결·일기·시간표 데이터는 유지됩니다.
