무엇을 도와드릴까요?

설치부터 일정 관리, Google 동기화와 백업까지
궁금한 내용을 빠르게 찾아보세요. 처음이라면 사용설명서부터 읽어보세요.

ONHARU는 Windows 배경화면 위, 바탕화면 아이콘 아래에 달력을 표시합니다. Google과 함께 봐야 하는 일정은 Google Calendar로, 개인 PC에만 둘 일정은 로컬로 나눠 한 화면에서 관리합니다.
현재 개인 명의 프리웨어 배포 단계라 유료 코드 서명이 적용되지 않았습니다. 반드시 onharu.app 또는 공식 GitHub Release에서 받은 파일인지 확인하고, 공식 SHA-256 값과 비교한 뒤 설치하세요.
위치 조정에서는 일반 창처럼 위치와 크기를 바꿉니다. 고정됨에서는 달력이 바탕화면 아이콘 아래로 들어가 아이콘을 그대로 선택하고 옮길 수 있습니다.
시간 일정도 ONHARU에서 완료 체크를 사용할 수 있습니다. 로컬 일정과 일반 Google Calendar 일정의 완료 표시는 이 PC에 저장하고, 실제 Google Task만 Google 완료 상태와 동기화합니다.
일기장은 Google로 보내지 않고 이 PC에 저장합니다. 날짜 숫자·음력 날짜·일기 표시점을 더블클릭해 작성하고, 상단 일기장 아이콘에서 검색·정렬·읽기가 가능합니다.
트레이의 ONHARU 아이콘을 우클릭해 화면에 보이기를 선택하세요. 해상도·표시 배율·주 모니터가 바뀐 경우에도 현재 화면 안으로 위치를 복구할 수 있습니다.
네. 시간표는 달력과 별도로 움직이는 독립 창입니다. 기본 9교시를 기준으로 요일·교시·시간·글자 크기를 정하고, 창을 닫지 않은 채 저장해 달력과 함께 사용할 수 있습니다.
프로야구 일정은 기본적으로 꺼져 있는 선택 기능입니다. 설정에서 기능을 켜고 Parse.bot KBO Schedule API 키를 등록하면 월별 일정을 불러올 수 있습니다. 원하는 경기만 선택해 확인하면 로컬 ‘야구’ 달력에 추가되며, 중복 경기는 다시 만들지 않습니다. API 키는 이 PC에 암호화해 보관하고, 새로고침할 때 제공 업체의 사용량이 차감될 수 있습니다.
네. 달력 인쇄 기능으로 현재 일정을 종이 또는 PDF 프린터로 출력할 수 있습니다. 출력 전 미리 보기에서 범위와 프린터 설정을 확인하세요.
Google 일정은 선택한 Google Calendar와 동기화됩니다. 업무·개인 로컬 일정, 기념일과 일기는 이 PC에 저장됩니다. 백업 복원은 Google 원본을 삭제하거나 덮어쓰지 않습니다.
아니요. ONHARU에서 만든 Google 일정은 먼저 로컬에 저장되고 실패하면 동기화 대기 상태로 남습니다. 네트워크가 복구된 뒤 동기화를 다시 실행하세요.
Google Tasks는 기본적으로 꺼져 있습니다. 설정의 Google Tasks 표시·동기화를 켜고 제한 사항 안내를 확인해야 동기화와 오른쪽 목록이 나타납니다. Google 일정 수정 권한에서 Task 목록을 허용하면 ONHARU에서도 Task를 만들고 제목·날짜·메모·완료 상태를 수정할 수 있습니다. Google에서 만든 Task는 완료 상태만 변경할 수 있습니다.
Google Tasks 공개 API는 반복 규칙·미래 반복 회차·설정된 시각을 제공하지 않습니다. ONHARU는 Google이 API로 제공한 현재 회차만 가져오며, 시간이 있는 Task도 날짜만 전달되므로 하루 종일로 표시합니다. ONHARU에서 새 Google Task를 만들 때도 반복·시간·알림·여러 날 일정은 지원하지 않습니다. 미래 회차와 정확한 시간이 필요한 일정은 Google Task가 아닌 Google Calendar 반복 일정 또는 ONHARU 반복 일정을 사용하세요.
네. 생일, Gmail에서 생성된 일정, 부재중, 집중 시간과 근무 위치는 Google의 원본 종류를 보존한 채 읽기 전용으로 표시합니다. ONHARU가 이를 일반 일정으로 바꾸거나 임의 수정하지 않습니다.
JSON은 ONHARU 로컬 일정의 정확한 백업·복원용, ICS는 다른 달력 앱과 일정을 주고받는 용도, CSV는 Excel에서 확인하거나 정리하는 용도입니다. 가져오기 전에는 추가할 항목을 선택해 확인할 수 있습니다.
아니요. ICS와 CSV로 가져온 일정은 항상 ONHARU의 로컬 일정으로 저장되며 Google Calendar 원본을 수정하지 않습니다. 내보낼 때 JSON과 ICS는 로컬 일정이 대상이고, CSV 전체 일정에는 화면에서 함께 보는 Google 일정과 로컬 일정이 포함될 수 있습니다.
여러 일정을 선택해 삭제할 때 ONHARU가 먼저 삭제 전 안전 백업을 만듭니다. 복구가 필요하면 해당 백업을 확인하세요. Google D-Day를 선택 삭제하는 경우에는 Google 원본 일정을 지우지 않고 ONHARU의 D-Day 표시만 제거합니다.
영향을 주지 않습니다. 자동 백업과 ONHARU JSON 가져오기는 로컬 일정만 대상으로 하며 Google 원본 일정은 Google에서 다시 동기화합니다.
프로그램 제거와 사용자 데이터 삭제는 구분됩니다. 다시 설치할 계획이 있다면 사용자 데이터를 보존하고, 완전 삭제할 때만 사용자 데이터까지 별도로 삭제하세요.
현재 바탕화면 레이어는 Windows 전용입니다. 모바일 앱은 장기 검토 중이며, 당장은 Google Calendar를 통해 휴대폰과 일정을 이어볼 수 있습니다.
현재 ONHARU의 기본 기능은 광고 없이 무료로 제공됩니다. 향후 Google 연동을 포함한 일부 선택 기능이 유료로 전환되거나 별도 요금제가 추가될 수 있습니다. 대상 기능, 가격, 시행일과 결제·해지·환불 조건은 적용 전에 안내하며, 명시적인 동의 없이 요금을 청구하지 않습니다.
네. Google 연결은 선택 사항입니다. 로컬 일정, Todo, D-Day, 기념일, 일기장, 시간표와 JSON 백업 등 PC 안에서 동작하는 기능부터 사용할 수 있습니다.
네. 일정·설정·연동 정보와 자동 백업은 %LOCALAPPDATA%\Onharu에 따로 저장되므로 프로그램을 업데이트해도 유지됩니다. 중요한 자료는 업데이트 전 JSON 내보내기로 한 번 더 보관하면 더욱 안전합니다.
ONHARU 2.2.1부터 하루 한 번 GitHub의 새 버전을 확인하고, 새 버전이 있을 때만 설치 여부를 묻습니다. 사용자가 승인하면 설치판을 받은 뒤 SHA-256을 검증하며 강제로 설치하지 않습니다. 2.1·2.2.0 사용자는 연결 문제를 고친 2.2.1을 최초 한 번 직접 설치해야 이후 자동 업데이트를 정상적으로 사용할 수 있습니다.
