# ONHARU 2.2.0

ONHARU 2.2.0은 2.1의 기능과 Explorer 레이어 동작을 유지하면서 화면 테마와 색상 체계를 정리한 디자인 업데이트입니다.

## 주요 변경

- 파스텔·블랙 두 가지 디자인 스킨과 빠른 전환 버튼
- 일정 배경·글자·체크박스·오른쪽 카드에 공통 색상 규칙 적용
- 다섯 가지 색상 프리셋과 사용자 색상 저장·교환·초기화
- 달력 기간, 이동·고정, 스포츠 보기의 공통 슬라이딩 버튼 규칙
- KBO 경기 일정 보기 크기 저장 및 다음 실행 시 복원
- 팝업 중복과 이동·고정 전환 충돌을 막는 공통 팝업 정책
- 시간표·일기장·KBO 창의 제목, 아이콘, 대표 버튼과 슬라이딩 옵션 통일
- 메인 상단과 부가기능 팝업의 시간표·일기장·야구 아이콘 통일
- 기존 일정, 설정, 일기, 시간표, Google 연결 정보 보존

## 설치 안내

- Windows 10·11 64비트 권장
- 기존 ONHARU 설치판 위에 그대로 설치해 업데이트 가능
- 코드 서명이 없는 설치판이므로 Windows에서 `알 수 없는 게시자` 안내가 표시될 수 있음
- 설치판과 함께 제공되는 SHA-256으로 파일 무결성을 확인 가능
