# 후속 기능 경계

## 별도 설계 후 구현

- 주간·일간·일정 탭: 주간 화면에 시간표·스터디 계획·학사일정을 결합하되 월간 렌더러와 분리한다.
- 일정별 색상: 카테고리 색상을 기본값으로 두고 일정 하나만 재정의하는 선택 필드로 설계한다.
- 창 동작 발견성: 로고 메뉴는 유지하되 별도 버튼 또는 최초 안내 중 하나를 작은 화면 시안으로 검토한다.
- Windows 우클릭 일정 등록: Explorer 셸 확장 설치·서명·제거 책임이 커서 별도 모듈과 설치 옵션으로만 검토한다.
- Free/Plus: 하나의 설치 파일과 서버 권한 판정을 사용한다. 7일 체험 후 Google 연동만 제한하는 안을 우선 검토하며, 로컬 일정·일기·시간표·백업은 Free로 유지한다.

## 구현 금지 경계

- 단순 로컬 파일이나 레지스트리 값만으로 Plus를 판정하지 않는다.
- 체험 종료 시 사용자의 기존 Google 일정 또는 로컬 데이터를 삭제·숨기지 않는다.
- 셸 확장 코드를 메인 WPF 실행 파일이나 Explorer 레이어 입력 코드에 섞지 않는다.
