# 활성 사용자·Google 연동 사용자 집계 설계

## 목표

개인 일정 내용이나 Google 계정 주소를 수집하지 않고 다음 두 수치만 파악한다.

- 일정 기간 내 ONHARU 활성 설치 수
- 그중 Google 연동 기능을 사용한 설치 수

## 중요한 한계

고유 사용자 수를 세려면 익명이라도 지속되는 식별자가 필요하다. 무작위 설치 ID도 개인정보 또는 온라인 식별자로 취급될 수 있으므로 고지·보존기간·삭제 방법이 필요하다. 식별자 없이 단순 요청 수만 받으면 실행 횟수는 알 수 있지만 사용자 수는 알 수 없다.

## 권장 최소안

- 최초 실행 시 무작위 설치 ID 생성. 이메일·PC 이름·IP 해시·Google 계정 ID는 사용하지 않는다.
- 전송 필드: 설치 ID의 서버 전용 해시, 앱 버전, OS 주 버전, `app_active` 또는 `google_sync_used`, 날짜 단위 시각.
- 일정 제목·날짜·카테고리·계정 주소·토큰·오류 원문은 절대 전송하지 않는다.
- 서버 원본 로그의 IP는 분석 데이터에 저장하지 않고 운영 로그도 짧게 보존한다.
- 앱 설정에 사용 통계 전송 설명과 끄기 항목을 둔다.
- 30~90일 내 일 단위 집계 후 원시 식별 기록을 삭제한다.

## 2.2.3 판정

서버와 개인정보 문구가 확정되지 않았으므로 구현하지 않는다. 화면 안정화와 별도 릴리스로 분리한다.
