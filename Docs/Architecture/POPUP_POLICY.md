# ONHARU 2.2 공통 팝업 정책

## 공통 이동 규칙

- 임시 `Popup`과 `ContextMenu`를 제외한 실제 ONHARU `Window`는 상단 60px의 빈 영역·제목 영역을 끌어 이동할 수 있다.
- 버튼, 입력칸, 체크박스·라디오 버튼, 목록, 슬라이더 등 조작 컨트롤 위에서는 창 드래그를 시작하지 않는다.
- 공통 `OnharuPopupChrome.Shell`을 쓰는 창은 자동 적용하고, 메인 달력에서 여는 창은 `PlaceCalendarDialog`에서 보완 적용한다.
- 독립 도구 창과 메인 차단 창 모두 같은 이동 규칙을 사용한다. 임시 팔레트·우클릭 메뉴는 이 규칙의 대상이 아니다.
- 실제 팝업의 스크롤바는 첫 화면이 그려지기 전 `Loaded` 단계에서 온하루 스타일로 확정한다. 기본 Windows 스크롤을 먼저 노출한 뒤 Dispatcher 작업으로 교체하지 않는다.

## 1. 독립 도구 창

메인 달력과 동시에 사용할 수 있고 종류별 한 창만 유지한다. 다시 실행하면 새 창을 만들지 않고 기존 창을 복원·활성화한다.

| 창 | 표시 방식 | 메인 입력 |
|---|---|---|
| `TimetableWindow` | modeless singleton | 허용 |
| `DiaryReaderWindow` | modeless singleton | 허용 |
| `SportsCalendarWindow` | modeless singleton | 허용 |
| `ReminderWindow` | 별도 STA thread | 허용 |

독립 창 내부의 편집·API 설정·날짜별 상세창은 해당 독립 창만 차단하는 자식 모달로 연다.

## 2. 메인 차단 팝업

`MainWindow.ShowBlockingDialog()`만 사용한다. 동시에 하나만 허용하며, 중복 요청은 기존 팝업 또는 그 자식 팝업을 앞으로 가져온다.

- 설정, 제품 업데이트, 종료 확인
- 새 일정·일정 수정·반복 삭제
- 일기 작성, 기념일 작성·수정
- 연·월 이동, 일정 검색
- 로컬 일정 제안·가져오기, 백업 복원, 일정 삭제
- 메일 보내기, 동기화 대기 일정, 안내·경고
- 프로야구 API 최초 설정

차단 중에는 메인 WPF 창과 Explorer 고정 레이어의 모든 입력을 막는다. 이동·고정, 4주·전체월, 날짜 이동, 투명도, 필터, 일정 입력을 예외로 두지 않는다. 메인 창을 `IsEnabled=false`로 만들면 날짜·체크박스의 비활성 스타일이 렌더링되므로, 시각 상태는 유지하고 `IsHitTestVisible=false`로 입력만 차단한다.

## 3. 자식 차단 팝업

설정창 또는 독립 도구 창에서 시작된 세부 작업이다. 부모 창의 `Owner`를 지정하고 일반 `ShowDialog()`를 사용한다.

- 설정의 제품 정보, 카테고리 순서, Google Tasks 경고, 계정 작업, 데이터 형식 선택
- 로컬 삭제 최종 확인
- 일기장 읽기의 일기 편집
- 시간표의 시간표 설정 (`TimetableSettingsWindow`, 2026-09-01 본 창의 접이식 패널에서 분리)
- KBO의 API 안내·설정 및 날짜별 경기 선택
- 인쇄의 Windows 인쇄 대화상자

## 4. 임시 팝업

WPF `Popup` 또는 `ContextMenu`를 사용한다. 하나의 선택만 받고 다른 곳을 클릭하면 닫힌다. 차단 팝업을 열기 전에는 `CloseTransientPopup()`으로 닫는다.

- 중요한 날·선택일·오늘 색상 팔레트
- 일정 날짜·반복 종료 날짜 달력
- 응원팀 드롭다운
- 닫기 우클릭 메뉴

## 공통 불변식

1. 메인 차단 팝업은 `ShowDialog()`를 직접 호출하지 않는다.
2. 독립 도구 창은 종류별 참조를 보관하고 중복 생성하지 않는다.
3. 차단 중 고정 레이어 입력은 모두 기존 팝업 활성화로 끝낸다.
4. WinForms 파일 선택·저장창도 `ShowBlockingFileDialog()`로 같은 차단 범위에 포함한다.
5. 독립 알림은 다른 모달과 별도 Dispatcher에서 작동한다.
6. 앱 종료 시 모든 독립 창도 함께 닫는다.

## 부가기능 창 디자인 규칙

- 시간표·KBO처럼 메인 달력과 함께 쓰는 독립 창은 `OnharuPopupChrome.FeatureHeading`의 24px 글리프 칸, 21px 굵은 제목, 공통 제목색을 사용한다. 아이콘 박스나 테두리는 두지 않는다. 검색·설정 팝업도 같은 규격이다.
- 저장·등록처럼 한 화면의 최종 동작은 `PrimaryButton`의 ONHARU 그라데이션을 사용한다. 보조 동작은 공통 `Button`을 사용한다.
- 둘 이상의 상호배타 보기·정렬 옵션은 개별 버튼을 나열하지 않고 `OnharuSegmentedSwitch`를 사용한다.
- 날짜 이동의 `« ‹ 제목 › » 오늘` 순서와 23px·27px 탐색 버튼 규격은 메인 달력과 KBO 창에서 동일하게 유지한다.
- 창별 기능색은 콘텐츠 강조에만 사용하고, 제목 글자·아이콘 박스·닫기·대표 버튼의 크기와 정렬은 임의로 바꾸지 않는다.
