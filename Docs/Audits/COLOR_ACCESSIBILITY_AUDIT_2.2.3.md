# ONHARU 2.2.3 색상 접근성 감사

기준일: 2026-08-25

## 결론

- 색상 계산은 `CategoryColorSystem`, 상태 버튼은 `OnharuStateColors`, 프리셋은 `OnharuColorPresets`로 분리되어 있다.
- 달력과 오른쪽 일정 카드는 같은 카테고리 배경·글자 계산을 사용한다.
- 중요한 일정의 사용자 지정 배경·글자도 같은 렌더링 경로를 사용하도록 통합했다.
- 파스텔은 옅은 배경과 같은 계열의 충분히 짙은 글자, 블랙은 진한 배경과 흰색에 가까운 글자를 기본으로 한다.

## 유지할 규칙

1. 본문 텍스트 명암비는 가능하면 WCAG AA 4.5:1 이상을 유지한다.
2. 선택 상태는 색만 바꾸지 않고 채움·테두리·체크 표시 중 둘 이상으로 구분한다.
3. 휴일은 빨강, 야구는 필드 그린을 기본 의미색으로 유지하되 사용자가 편집할 수 있다.
4. 팝업 테두리를 대표색으로 전면 치환하지 않는다. 경고·삭제 의미색과 충돌할 수 있으므로 공통 중립 테두리를 유지하고 주요 동작 버튼에만 대표색을 쓴다.
5. 임의 화면에서 HEX 값을 직접 하드코딩하지 않고 공통 색상 모듈을 거친다.

## 후속 시각 검증

- 실제 파스텔/블랙 화면에서 업무·개인·Google·D-Day·기념일·야구 카드의 작은 글자를 확인한다.
- 100%, 125%, 150% 배율에서 체크박스 테두리와 선택 상태를 확인한다.
- 색각 이상 시뮬레이션은 별도 후보에서 수행한다.
