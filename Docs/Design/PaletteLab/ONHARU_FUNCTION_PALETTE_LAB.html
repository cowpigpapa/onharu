ONHARU 팔레트랩 설명

다섯 색상 계열을 기준으로 실제 ONHARU 적용 위치를 선택합니다. 같은 계열 안에서는 H → S → L 순으로 가까운 색끼리 배열됩니다.

H · Hue · 색상
0° 빨강 → 60° 노랑 → 120° 초록 → 180° 시안 → 240° 파랑 → 300° 보라의 색상환 위치입니다.
S · Saturation · 채도
0%는 회색에 가깝고 100%는 가장 선명합니다. 일정 색은 구분되면서 눈부시지 않은 중간~높은 채도가 안전합니다.
L · Lightness · 명도
0%는 검정, 50%는 본색, 100%는 흰색입니다. ONHARU 파스텔 면은 기준색을 흰색과 섞어 별도로 생성합니다.

스킨 미리보기: 왼쪽 흰 배경은 파스텔 스킨의 실제 일정 면·같은 계열 진한 글씨, 오른쪽 검은 배경은 블랙 스킨의 실제 일정 면·흰 글씨입니다.
