# ONHARU 기능별 팔레트 랩

## 화면 배치

- 설명은 상단에서 접고 펼칠 수 있습니다.
- 실제 적용 위치는 상단 고정 영역에서 선택합니다.
- 왼쪽 고정 패널에는 스킨·배열 옵션과 배경·글씨 조합 실험을 배치하고, 오른쪽에는 스크롤 가능한 팔레트를 배치합니다.

## 보기 방식과 색상 계열

- `파스텔 + 블랙`, `파스텔만`, `블랙만`으로 스킨 결과를 분리해 볼 수 있습니다.
- `개별 색상`은 실제 적용 위치에 색을 선택하는 화면이고, `계열 팔레트 묶음`은 한 계열의 기준색·파스텔·블랙 결과를 한눈에 비교하는 화면입니다.
- `빨·주·노·초·파·남·보`는 모든 후보를 H값으로 다시 분류한 색상환 팔레트입니다. 원래 프리셋 계열과 무관하게 비슷한 색끼리 비교할 때 사용합니다.
- `조합 팔레트`는 서로 다른 색상 계열 중 채도와 명도가 어울리는 7색을 한 묶음으로 보여줍니다. 색을 하나씩 고르거나 현재 대상에 필요한 개수를 한 번에 선택할 수 있습니다.
- 앱에서 사용자가 좋다고 확인한 `맑은균형 기본 조합`과 `중요 일정 6색 조합`은 실제 코드의 HEX 값을 그대로 보존한 기준 팔레트입니다. 중요 일정의 회색은 취소용 중립색이므로 조합에서 제외합니다.
- 조합 팔레트에는 색별 HSL과 조합 전체의 H·S·L 평균 및 범위를 함께 표시합니다. 색상 느낌을 전달할 때는 예를 들어 `H는 다양하게, S 60~75%, L 42~55%`처럼 표현할 수 있습니다.
- 상단의 배경·글씨 조합 실험에서 두 색을 각각 선택하거나 HEX로 입력하면 실제 일정 카드와 WCAG 대비율이 즉시 표시됩니다. 일반 글씨는 4.5:1 이상을 기본 통과 기준으로 사용합니다.
- 아래 팔레트에서 색을 선택하면 현재 스킨의 배경·글씨 조합이 상단 실험기에 자동 반영됩니다. `파스텔 + 블랙`은 파스텔을 기본으로 하고, `블랙만`은 블랙 조합을 사용합니다.
- 왼쪽에서 `배경색 선택` 또는 `글씨색 선택`을 정한 뒤 팔레트 색을 누르면 해당 항목만 바뀝니다. HEX 문자열 영역은 팔레트 선택과 분리되어 드래그 선택·복사가 가능합니다.
- 팔레트에서는 후보색 한 개만 강조됩니다. 배경·글씨 조합을 확인한 뒤 `선택색 모음에 추가`해야 현재 적용 위치의 선택 수에 포함되며, 필요한 개수까지만 추가할 수 있습니다.
- 업무·개인·야구는 `ONHARU 일정 카테고리 세트`, D-Day·기념일·휴일은 `Special Day 세트`로 묶어 조합 단위로 결정합니다.
- 개별 색상·계열 팔레트·조합 팔레트·색상환 팔레트 어디에서든 색상을 선택할 수 있습니다.
- 앱 기본 프리셋은 단일 대표색 5계열이 아니라 밝기와 분위기가 다른 5개의 혼합 색상 조합입니다. 블루·핑크·그린·바이올렛·오렌지·옐로는 각 조합 안에서 카테고리를 구분하는 재료로 사용합니다.
- 옐로·골드는 가독성을 검토하기 위한 비교 후보입니다. 순수 노랑 대신 골드·머스터드 계열만 포함했습니다.
- 레드/코랄은 휴일·경고 의미와 충돌하고, 틸은 블루·그린과 중복되므로 독립 기본 프리셋에는 추가하지 않습니다.

`ONHARU_FUNCTION_PALETTE_LAB.html`은 색을 코드에 즉시 반영하는 도구가 아니라, 사용자와 함께 기능별 후보색을 결정하는 오프라인 선택 도구다.

## HSL

- `H(Hue)`는 색상환의 위치다. 0° 빨강, 60° 노랑, 120° 초록, 180° 시안, 240° 파랑, 300° 보라로 이어진다.
- `S(Saturation)`는 채도다. 0%는 무채색, 100%는 가장 선명한 색이다.
- `L(Lightness)`는 명도다. 0%는 검정, 50%는 본색, 100%는 흰색이다.
- 랩은 각 색상 계열 안에서 H, S, L이 가까운 후보를 함께 비교할 수 있게 배열한다.
- 각 기준색은 흰 배경의 파스텔 스킨과 검은 배경의 블랙 스킨으로 동시에 미리 본다. 파스텔 면·같은 계열 진한 글씨와 블랙 면·흰 글씨는 앱의 `CategoryColorSystem`과 같은 계산식을 사용한다.

## 실제 코드에서 확인한 색상 수

- 추천 프리셋: 12색. 업무·개인·야구·D-Day·기념일·휴일과 Google 변형 6색이다.
- 대표색: 1색. 상단 주요 선택 버튼, 투명도, 이동·고정 등의 공통 강조에 사용한다.
- 중요 일정: 7쌍. 배경 7색과 같은 계열 글씨 7색이 짝을 이룬다.
- 선택일 배경·테두리, 오늘 배경·날짜 원형: 각각 7색 임시 팔레트다.
- 날짜 배경 빠른색: 6색, ONHARU 로고: 9색, 시간표 요일: 7색이다.
- 달력 일정 막대와 오른쪽 상세 카드는 같은 기준색에서 동일한 배경·글씨 공식을 사용한다. 체크박스, 테두리와 블랙 스킨 색은 `CategoryColorSystem`에서 자동 파생한다.

Google 캘린더 원색, 국경일의 의미색, 음력·24절기 중립색처럼 프리셋과 완전히 같은 방식으로 묶으면 안 되는 항목도 왼쪽 적용 위치에 분리해 두었다.
