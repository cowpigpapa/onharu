# 테스트용 컨트롤 색상 팔레트

`App/TemporarySegmentPaletteTool.cs`는 슬라이딩 버튼의 배경색과 글씨색을 실행 중에 시험하는 개발 도구다.

- 대상 컨트롤에서 마우스 오른쪽 버튼을 누르면 팔레트가 열린다.
- 배경과 글씨를 각각 선택할 수 있다.
- 설정에는 저장하지 않으며 앱을 다시 실행하면 공식 테마 색으로 돌아간다.
- 새 컨트롤에 붙일 때는 생성 직후 `TemporarySegmentPaletteTool.Attach(control);` 한 줄을 추가한다.
- 실험 UI에서 제거할 때는 `Attach` 호출만 삭제한다. 도구 파일은 다음 색상 실험을 위해 유지한다.

향후 요청 문구 예시: `테스트용 색상 팔레트에 이 색 조합을 추가하고 ○○ 버튼에 붙여줘.`
