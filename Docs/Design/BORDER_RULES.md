# ONHARU 테두리·구분선 규칙

## 기본 원칙

- 테두리는 장식이 아니라 영역·상태·조작 가능성을 구분할 때만 사용한다.
- 테두리가 있는 요소는 배경색에서 같은 색조를 유지하면서 배경보다 한 단계 진한 색을 사용한다. 고정 RGB를 사용하지 않는다.
- 테두리 대비는 배경과 충분히 구분되되, 검정/흰색처럼 과도하게 강하지 않게 한다. 기본 두께는 1px이다.
- 사용자가 색을 바꾸면 배경·글씨·테두리를 한 세트로 갱신한다. 테두리가 없는 요소에는 테두리를 새로 만들지 않는다.

## 요소별 적용

| 요소 | 테두리 | 기준 |
|---|---|---|
| 일정 카드 | 있음 | 카드 배경의 동일 색조를 약간 어둡게 |
| D-Day·기념일 카드 | 있음 | 바깥 카드와 안쪽 표면, 내부 구분선을 같은 파생색으로 동기화 |
| 스페셜 일정 내부 구분선 | 있음 | 카드 테두리와 같은 색조, 1px 이하의 시각적 강도 |
| 슬라이딩 버튼 | 바깥쪽만 있음 | 컨트롤 그룹 경계만 표시, 선택된 안쪽 버튼은 배경색으로 구분 |
| 일반 기능 버튼·아이콘 | 기본 없음 | 호버/선택 상태가 필요한 경우에만 테마색 테두리 |
| 로그인·로그아웃 | 있음 | 계정 영역을 분리하는 경계. 글씨와 배경 대비를 우선 |
| 스크롤바 | 트랙 중립, 손잡이 테마색 | 손잡이에만 색을 사용하고 별도 외곽 테두리는 만들지 않음 |

## 색상 도구

색상 도구에서 테두리가 있는 대상을 선택하면 `BorderBrush(background)`로 자동 계산한다. 명시적으로 투명한 테두리인 대상은 계속 테두리 없음으로 유지한다. 특수 카드는 바깥 테두리와 안쪽 표면 및 구분선까지 동시에 갱신해야 한다.
