# ONHARU 메인 헤더·버튼 디자인 기준

이 문서는 ONHARU 2.2 메인 달력에서 확정된 아이콘 크기, 버튼 치수, 정렬 기준선의 단일 기준이다. 이후 헤더를 수정할 때는 개별 버튼의 Margin을 임의 조절하기 전에 이 문서와 `MainWindow.Layout.cs`, `OnharuSegmentedSwitch.cs`를 함께 확인한다.

## 공통 버튼

- 일반·아이콘 버튼은 테두리 1px, CornerRadius 10을 사용한다.
- 아이콘 전용 버튼은 Padding 0이며 콘텐츠는 가로·세로 중앙 정렬한다.
- 기본 hover 반전은 사용하지 않는다. 마우스는 손 모양으로 바뀌고, 누르는 순간에만 Opacity 0.62 피드백을 준다.
- 파스텔 아이콘은 검정 계열, 블랙 아이콘은 흰색을 사용한다. 닫기·삭제·경고 같은 의미색만 예외다.
- 벡터 아이콘은 기본 17×17 Viewbox, 약 1.8px 둥근 획을 사용한다.
- 시간표 `▦`, 일기 `✎`, 야구 `⚾`처럼 글리프 기반 부가기능 아이콘은 21×21 Viewbox를 사용한다.

## 메인 왼쪽 헤더

- 로고: 44×44, Padding 7, CornerRadius 12.
- 브랜드명과 날짜 제목: 17px 고정.
- 이전·다음 버튼: 20×23, 글자 12.5px, Padding 0.
- 상단 오늘 버튼: 42×23, 글자 12.5px SemiBold.
- `<`, `오늘`, `>` 사이 간격: 각각 3px.
- 오늘 버튼은 ONHARU 그라데이션을 사용하며 파스텔·블랙에서 동일하다.
- 로고 메뉴는 로고 오른쪽, 달력 안쪽에 표시하며 항목은 `취소 / 최소화 / 종료`다.

## 메인 오른쪽 헤더

- 오른쪽 동작 영역 폭은 사이드바 열과 같은 310px다.
- 상단 아이콘 버튼 높이는 28px다.
- 검색·설정 버튼 폭은 34px, 시간표·일기·야구 버튼 폭은 32px다.
- 패널 접기·펴기 버튼은 28×27이며 오른쪽 끝이 메인 달력 오른쪽 선과 일치한다.
- 투명도 슬라이더와 기간 스위치의 왼쪽은 오른쪽 상세 패널의 왼쪽 선과 일치한다.
- 이동·고정 스위치의 오른쪽은 오른쪽 상세 패널의 오른쪽 선과 일치한다.
- 기간 스위치는 왼쪽, 이동·고정은 오른쪽에 고정하고 파스텔·블랙 전환을 두 버튼 사이에 항상 표시한다.
- 접기·펴기 및 세 슬라이딩 스위치 행은 상단 아이콘 행 아래에 2px 간격을 둔다.

## 슬라이딩 버튼

- 외곽 높이 27px, Border 1px, Padding 1px, CornerRadius 10.
- 내부 선택 면 높이 23px, CornerRadius 8.
- 글자 12.5px SemiBold.
- 각 내부 폭은 실제 글자 측정값 + 좌우 2px씩으로 계산한다. 글자 수가 다른 항목을 억지로 같은 폭으로 만들지 않는다.
- 비활성 영역은 투명 클릭 면만 사용하고 hover 반전을 표시하지 않는다.
- 기간 스위치와 오른쪽 상세 범위 탭의 선택색, 투명도 슬라이더는 현재 프리셋 대표색을 사용한다. 파스텔 스킨에서도 이 강조색은 흐리게 바꾸지 않는다.

## 오른쪽 상세 패널

- 패널 외곽 Margin은 왼쪽 12px, 내부 Padding은 9px다.
- 범위 탭은 `선택 날짜 / 이번 주 / 다음 주` 세 개다.
- 선택 날짜는 왼쪽, 이번 주는 중앙, 다음 주는 오른쪽에 고정하고 두 간격을 동일하게 분배한다.
- 세 버튼은 각각 88px, 높이는 31px다. 오른쪽 상세의 292px 가용 폭에서 왼쪽·오른쪽 끝을 고정하고 두 사이 간격을 약 14px로 동일하게 분배한다. `MainWindow.Layout.cs`에서 폭을 다시 덮어쓰지 않는다.
- 선택 상태는 현재 프리셋 대표색과 흰 글자, 미선택 상태는 스킨 공통 Button·Grid·Muted 역할색을 사용한다.

## 검증 체크리스트

- 100%와 125% DPI에서 아이콘이 잘리거나 한쪽으로 치우치지 않는다.
- 패널 접기 버튼, 상세 패널 왼쪽·오른쪽 기준선이 각각 정확히 일치한다.
- 기간·이동 스위치가 각각 오른쪽 패널의 왼쪽·오른쪽 기준선과 일치한다.
- 파스텔·블랙 전환 후 아이콘·버튼 테두리와 글자 대비가 유지된다.
- 이동·고정 상태에서 동일한 좌표와 클릭 영역을 사용한다.
