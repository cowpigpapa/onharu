# ONHARU 메인 헤더·버튼 디자인 기준

이 문서는 ONHARU 2.2 메인 달력에서 확정된 아이콘 크기, 버튼 치수, 정렬 기준선의 단일 기준이다. 이후 헤더를 수정할 때는 개별 버튼의 Margin을 임의 조절하기 전에 이 문서와 `MainWindow.Layout.cs`, `OnharuSegmentedSwitch.cs`를 함께 확인한다.

## 공통 버튼

- 일반·아이콘 버튼은 테두리 1px, CornerRadius 10을 사용한다.
- 아이콘 전용 버튼은 Padding 0이며 콘텐츠는 가로·세로 중앙 정렬한다.
- 기본 hover 반전은 사용하지 않는다. 마우스는 손 모양으로 바뀌고, 누르는 순간에만 Opacity 0.62 피드백을 준다.
- 파스텔 아이콘은 검정 계열, 블랙 아이콘은 흰색을 사용한다. 닫기·삭제·경고 같은 의미색만 예외다.
- 아이콘 도형의 단일 기준은 `App/OnharuIcons.cs`다. 18×18 좌표계에 그리고 1.6px 둥근 획을 사용하며, Viewbox가 표시 크기로 맞춘다.
- 메인 헤더에 나란히 서는 다섯 아이콘 `⌕ ▦ ◴ ⚾ settings`는 모두 21px 표시 크기를 사용한다. 이동·달력 화살표 같은 보조 기호는 17px이다.
- 설정창 헤더의 인쇄·정보 버튼도 같은 21px 도형을 쓴다. 버튼은 30×26이며 닫기 버튼(26px)과 높이를 맞춘다. 도형을 창 안에 다시 그리지 않고 `SettingsWindow.HeaderToolButton`이 `OnharuIcons`에서 받는다.
- 오른쪽 상세의 도구 버튼 넷(미완료·카테고리순·시간순·추가)과 기념일 카드의 만들기 버튼은 모두 18×18이며 글리프는 기본 크기를 쓴다. 12px로 줄이는 안은 너무 작아 쓰지 않는다.
- `add` 십자는 18칸 안에서 4~14를 쓴다. 이전 5~13은 형제 아이콘(3~15)보다 좁아 같은 버튼 안에서 혼자 작아 보였다.
- 2026-09-02에 설정 톱니·알람·시간표 도형을 다시 그렸다. 톱니는 실제 이빨 여섯을 가진 닫힌 윤곽, 알람은 둥근 종 둘과 다리를 가진 알람시계, 시간표는 머리줄과 왼쪽 시간열을 가진 표다. 이전 도형은 각각 조타륜·안테나·3칸 표처럼 읽혔다.

## 메인 왼쪽 헤더

- 로고: 44×44, Padding 7, CornerRadius 12, 오른쪽 간격 8px.
- 브랜드명과 날짜 제목: 17px 고정.
- **연·월 제목 옆에 이동 버튼을 두지 않는다(2026-09-03 확정).** `‹ • ›` 세 버튼을 없앴다. 월·주 이동은 달력 요일 행 양 끝의 `‹ ›`(한 주 이동, 더블클릭 한 달 이동), 임의 날짜 이동은 제목 클릭으로 열리는 날짜 선택기, 오늘로 이동은 오른쪽 상세 `선택 날짜` 탭 더블클릭이 담당한다.
- 연·월 제목 줄에는 제목만 둔다. `monthNavigation`은 1열 Grid다.
- 로고 메뉴는 로고 오른쪽, 달력 안쪽에 표시하며 항목은 `취소 / 최소화 / 종료`다.

## 메인 오른쪽 헤더

- 오른쪽 동작 영역 `actionArea`의 폭은 390px, 높이는 55px다. 오른쪽 상세 패널 열은 310px로 별개 값이다.
- 상단 아이콘 버튼은 다섯 개 모두 34×28이며 서로의 간격은 4px다.
- 패널 접기·펴기 버튼은 14×34이며 오른쪽 끝이 메인 달력 오른쪽 선과 일치한다.
- 투명도 슬라이더와 기간 스위치의 왼쪽은 오른쪽 상세 패널의 왼쪽 선과 일치한다.
- 이동·고정 스위치의 오른쪽은 오른쪽 상세 패널의 오른쪽 선과 일치한다.
- 기간 스위치는 왼쪽, 이동·고정은 오른쪽에 고정하고 파스텔·블랙 전환을 두 버튼 사이에 둔다. 이 전환은 기본으로 표시하되 설정에서 숨길 수 있다(`ShowThemeSwitch`).
- 상단 아이콘 행(28px)과 슬라이딩 스위치 행(26px) 사이 간격은 1px이다.
- 상단 아이콘 줄은 **오른쪽이 창 조작 버튼 왼쪽에 고정**이다. 설정에서 아이콘을 하나씩 켤 때마다 왼쪽으로 늘어난다.
- **전부 켰을 때만** 맨 왼쪽 아이콘의 왼쪽이 기간 스위치의 왼쪽과 한 선에 선다. 맞추는 기준은 `컨트롤은 테두리를, 글자는 글자를 같은 기준선에 세운다`이므로, 아이콘 획이 아니라 **아이콘 버튼의 테두리**를 스위치 테두리에 맞춘다. 헤더 아이콘 버튼은 흰 배경과 옅은 테두리가 보이는 컨트롤이기 때문이다.
- `AlignFeatureIconsToRangeSwitch`는 배치 후 실제 좌표를 재서 `featureArea`의 오른쪽 여백을 보정한다. 기준은 현재 보이는 줄이 아니라 **전부 켰을 때의 줄 너비**(`FullFeatureRowWidth`)다. 보이는 첫 아이콘을 기준으로 삼으면 아이콘을 하나만 켜도 줄 전체가 왼쪽으로 끌려간다(2026-09-03 회귀).
- 보정은 아이콘 한 칸 폭(`MaxFeatureRowShift = 38`)까지만 허용한다. 아래 줄에서 스킨 스위치를 숨기면 기준선이 그보다 크게 밀리는데, 거기까지 따라가면 아이콘이 창 조작 버튼 위로 올라탄다.

## 슬라이딩 버튼

- 외곽 높이 24px, Border 1px, Padding 1px, CornerRadius 10.
- 내부 선택 면 높이 22px, CornerRadius 8.
- 글자 12.5px SemiBold.
- 각 내부 폭은 실제 글자 측정값 + 좌우 2px씩으로 계산한다. 글자 수가 다른 항목을 억지로 같은 폭으로 만들지 않는다.
- 비활성 영역은 투명 클릭 면만 사용하고 hover 반전을 표시하지 않는다.
- 기간 스위치와 오른쪽 상세 범위 탭의 선택색은 현재 프리셋 대표색을 사용한다. 파스텔 스킨에서도 이 강조색은 흐리게 바꾸지 않는다.
- **투명도 슬라이더는 슬라이딩 버튼 줄 왼쪽에 둔다(2026-09-03 확정).** 이전에는 브랜드 줄에 있어 브랜드 표기 영역에 조작 컨트롤이 섞였다. 기간·스킨·이동/고정과 한 줄에 모아 조작 층위를 분명히 한다. 그 줄은 폭 384 중 스위치가 288을 써서 왼쪽 96px이 비어 있다.
- 슬라이더 색은 같은 줄의 중립 스위치와 맞춘다. `MainWindow.Theme.cs`의 `OpacitySliderBrush()` 한 곳에서 정하며 생성 시점과 테마 적용 시점이 같은 함수를 쓴다. `theme-check.ps1`이 둘 다 검사한다.

## 오른쪽 상세 패널

- 패널 외곽 Margin은 왼쪽 12px, 내부 Padding은 9px다.
- 범위 탭은 `선택 날짜 / 이번 주 / 다음 주` 세 개이며 개별 버튼이 아니라 하나의 슬라이딩 스위치 `detailPeriodSwitch`다.
- 스위치 전체 폭 278px, 높이 24px이고 각 칸은 92px로 같다. 슬라이딩 버튼 공통 규격을 그대로 따른다.
- `선택 날짜` 칸을 더블클릭하면 오늘로 이동한다.
- 선택 상태는 **두 스킨 모두 밝은 블루 `#3B82F6`과 흰 글자**를 사용한다(2026-09-03 확정). 미선택 상태는 스킨 공통 Button·Grid·Muted 역할색을 쓴다. 색은 `OnharuStateColors.DetailPeriodTab` 한 곳에서만 정한다.
- `#3B82F6`은 선택일 테두리 기본값과 같은 값이다. 이 제품에서 파랑은 이미 `현재 선택`을 뜻하므로 새 색을 들이지 않는다. 파스텔의 보라는 상세 회보라 카드와, 블랙의 피치는 KBO 갈색과 계열이 겹쳤다.
- 이전 문구의 `프리셋 대표색`과 하드코딩 `#4338CA`는 구현과 맞은 적이 없어 걷어냈다.

## 검증 체크리스트

- 100%와 125% DPI에서 아이콘이 잘리거나 한쪽으로 치우치지 않는다.
- 패널 접기 버튼, 상세 패널 왼쪽·오른쪽 기준선이 각각 정확히 일치한다.
- 기간·이동 스위치가 각각 오른쪽 패널의 왼쪽·오른쪽 기준선과 일치한다.
- 파스텔·블랙 전환 후 아이콘·버튼 테두리와 글자 대비가 유지된다.
- 이동·고정 상태에서 동일한 좌표와 클릭 영역을 사용한다.
- 125% DPI에서도 창의 논리 폭을 최소 720px로 보장해 헤더가 서로 침범하지 않는다.
