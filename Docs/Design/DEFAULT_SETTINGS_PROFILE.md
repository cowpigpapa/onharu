# ONHARU 신규 설치 기본 설정 기준

기준일: 2026-08-24  
적용 범위: `settings.json`이 없는 완전 신규 설치

## 보존 원칙

- 업데이트, 덮어쓰기, 재설치에서 기존 `%LOCALAPPDATA%\Onharu\settings.json`이 있으면 사용자 값을 그대로 사용한다.
- 새 버전의 기본값을 기존 사용자에게 강제로 덮어쓰지 않는다.
- 저장값이 손상됐거나 허용 범위를 벗어난 경우에만 `LocalStorage.LoadSettings()`의 안전 보정을 적용한다.

## 구현 기준

- 기본값의 단일 기준은 `App/PlannerSettings.cs`다.
- 창 초기화 코드는 기본값을 다시 정의하지 않고 저장값 또는 `PlannerSettings` 값을 사용한다.
- `feature-pack-check.ps1`에서 달력·위치·스킨·글자·투명도·팔레트·자동 이월 기본값을 회귀 검사한다.
