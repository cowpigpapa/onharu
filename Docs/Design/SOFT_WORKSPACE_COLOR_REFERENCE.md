# Soft Workspace 색감 기준

2026-08-28 사용자가 제공한 밝은 생산성 UI 이미지를 ONHARU `내설정` 색감 기준으로 기록한다. 특정 서비스의 화면 구조를 복제하지 않고 톤·명도·채도 관계만 참고한다.

## 관찰한 화면색

| 역할 | 이미지 추출색 | 성격 |
|---|---:|---|
| 선택 블루 면 | `#AECBFA` | 밝지만 선택 상태가 분명한 저채도 블루 |
| 옐로 면 | `#FEEFC3` | 크림에 가까운 따뜻한 옐로 |
| 그린 면 | `#CEEAD6` | 회색기가 섞인 안정적인 민트 그린 |
| 코랄 면 | `#FAD2CF` | 경고처럼 보이지 않는 부드러운 코랄 |
| 보조 블루 면 | `#E8F0FE` | 아이콘·보조 선택에 적합한 매우 밝은 블루 |
| 중립 컨트롤 | `#EAEBED` | 흰 배경과 부드럽게 구분되는 회색 |

## 톤 원칙

- 면색 명도는 대체로 88~95% 수준으로 유지한다.
- 채도는 중간 이하로 낮추고 흰색이 충분히 섞인 인상을 만든다.
- 한 화면에서 블루·옐로·그린·코랄을 같은 강도로 반복하지 않는다. 실제 정보가 있는 카드에만 한 색씩 배정한다.
- 선택 상태는 면색을 진하게 만들기보다 같은 계열의 선명한 2px 테두리로 구분한다.
- 글씨는 `#202124`에 가까운 거의 검정색을 사용하고 유채색 글씨를 겹치지 않는다.
- 흰 배경과 카드 사이에는 그림자보다 6~10% 명도 차이를 우선한다.

## ONHARU `내설정` 기준색

ONHARU는 기준색을 파스텔 면으로 자동 변환하므로 이미지의 완성 면색이 아니라 해당 색조의 기준색을 저장한다.
