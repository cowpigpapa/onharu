# ONHARU 자동 업데이트 시험 가이드

## 실제 동작

ONHARU는 GitHub의 최신 정식 Release를 하루 한 번 비차단으로 확인한다. 설치를 강제하지 않으며, 사용자가 승인한 경우에만 Setup EXE와 `SHA256SUMS.txt`를 내려받는다. 설치 파일의 SHA-256이 일치할 때만 실행한다.

## 정식 배포 전 시험

1. 현재 사용자 데이터 폴더 `%LOCALAPPDATA%\Onharu`를 백업한다.
2. GitHub에 현재 설치본보다 높은 버전의 정식 Release를 게시한다. Draft와 Prerelease는 `/releases/latest` 시험 대상이 아니다.
3. 이전 버전 ONHARU를 실행한다. 자동 확인은 하루 한 번이므로 `settings.json`의 `LastUpdateCheckUtc`를 이전 날짜로 바꾸거나 별도 시험 계정에서 실행한다.
4. 새 버전 안내 창에서 버전·변경 내용을 확인하고 `업데이트 설치`를 누른다.
5. 설치판 다운로드와 SHA-256 검증 완료 문구가 나온 뒤 설치 프로그램이 열리는지 확인한다.
6. 기존 설치 위치에 덮어쓴 뒤 일정·설정·일기·시간표·Google 연결이 유지되는지 확인한다.
7. 설치 후 제품 버전과 GitHub Release 버전, 웹 다운로드 버전이 같은지 확인한다.

업데이트 확인은 하루 한 번이다. 이전 버전이 새 Release 공개 전에 이미 확인했다면 같은 날 재실행해도 다시 조회하지 않는다. 시험에서는 Release 공개 후 `LastUpdateCheckUtc`를 안전하게 이전 날짜로 초기화하거나 전용 시험 데이터 폴더를 사용한다.

## 안전한 이전 버전 → 다음 패치 실기기 시험

- 이전 정식 설치판이 있는 시험 PC에서 더 높은 PATCH Release를 게시한 뒤 이전 버전을 실행해 실제 업데이트 안내를 확인한다.
- 주 사용 PC에서 시험할 때는 먼저 `%LOCALAPPDATA%\Onharu`를 복사해 둔다.
- 앱과 GitHub Release 버전이 같으면 업데이트를 표시하지 않는 것이 정상이다.

## 실패해야 정상인 경우

- Setup EXE가 없거나 `SHA256SUMS.txt`가 없으면 업데이트를 제안하지 않는다.
- 파일명에 해당하는 SHA-256이 없거나 실제 해시가 다르면 설치 프로그램을 실행하지 않는다.
- 네트워크 오류 시 앱 본체는 계속 동작하며 다음 확인 때 다시 시도한다.
